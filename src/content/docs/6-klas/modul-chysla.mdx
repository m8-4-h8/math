<Pravylo>
**Модуль** числа $a$ — відстань від початку відліку до точки з координатою $a$. Позначають $|a|$.

Модуль додатного числа і нуля — саме це число, а модуль від'ємного — протилежне до нього число:
$|5| = 5$, $\;|0| = 0$, $\;|-5| = 5$. Модуль **ніколи не буває від'ємним**.
</Pravylo>

:::note[Швидко нагадати]
- Модуль — відстань до нуля: $|-7| = 7$, $\;|7| = 7$, $\;|0| = 0$.
- Протилежні числа мають рівні модулі: $|-2{,}5| = |2{,}5| = 2{,}5$.
- Спершу модулі, потім дії: $|-8| + |3| = 8 + 3 = 11$.
- $|x| = 4$ — два числа: $x = 4$ або $x = -4$. А $|x| = -4$ — жодного.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Що це таке

**Спершу — з життя.** Ліфт стоїть на першому поверсі. Якщо він поїде на $3$ поверхи вгору ($+3$) чи на $3$ поверхи вниз, у
підвал ($-3$), — проїде однакову відстань: $3$ поверхи. Напрямок різний, а **відстань** однакова. Ця відстань без знака і є модуль.

**Тепер — малюнок.** Дужки під прямою — відстані від точок до нуля.

<KoordynatnaPriama min={-6} max={6} tochky={[{ nazva: 'A', x: -4 }, { nazva: 'B', x: 3 }]} modul />

**І лише тепер — правило.**

$$
|a| = a, \text{ якщо } a \ge 0 \qquad\qquad |a| = -a, \text{ якщо } a < 0
$$

Друга рівність тільки здається дивною: якщо $a$ від'ємне, то $-a$ — **додатне**. Наприклад, $|-7| = -(-7) = 7$.

:::tip[Чому модуль ніколи не від'ємний]
Модуль — це **відстань**, а відстань не буває від'ємною. Від $0$ до $-5$ — п'ять кроків, як і від $0$ до $5$, тому
$|-5| = |5| = 5$. Знак показує лише, у який бік іти, а модуль — як далеко.
:::

## Приклад

**Обчисли: $|-8| + |3| - |-5|$.**

1. Спершу модулі: $|-8| = 8$, $\;|3| = 3$, $\;|-5| = 5$.
2. Тепер дії: $8 + 3 - 5 = 6$.
3. **Перевірка:** усі модулі вийшли без мінуса ✓, і $8 + 3 = 11$, $\;11 - 5 = 6$ ✓

## Спробуй сам

<Zavdannia vidpovid="−7" pidkazka="На відстані 7 від нуля — дві точки: праворуч і ліворуч.">
  Модуль числа $x$ дорівнює $7$. Яким може бути $x$? Запиши менше з двох чисел.

  <span slot="rozviazok">$x = 7$ або $x = -7$; менше — $-7$. Перевірка: $|-7| = 7$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Модуль із мінусом.** $|-7| = -7$ — неправильно: модуль — відстань, він без мінуса, $|-7| = 7$. Як помітити: якщо після
знаходження модуля лишився мінус — помилка.

**Рівняння $|x| = a$.** Розв'язків **два**, а не один: $|x| = 4$ має корені $4$ і $-4$. А якщо праворуч від'ємне число,
наприклад $|x| = -3$, розв'язків **немає**: відстань не буває від'ємною.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="12" pidkazka="Модуль — відстань до нуля.">
  Знайди $|-12|$.

  <span slot="rozviazok">$|-12| = 12$</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="Спершу модулі: 3,6 і 2,4.">
  Обчисли: $|-3{,}6| + |2{,}4|$.

  <span slot="rozviazok">$3{,}6 + 2{,}4 = 6$</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="|−15| = 15, |−9| = 9.">
  Обчисли: $|-15| - |-9|$.

  <span slot="rozviazok">$15 - 9 = 6$</span>
</Zavdannia>

<Zavdannia vidpovid="−4" pidkazka="Два числа на відстані 4 від нуля.">
  Розв'яжи рівняння $|x| = 4$. Запиши менший корінь.

  <span slot="rozviazok">$x = 4$ або $x = -4$; менший — $-4$.</span>
</Zavdannia>
