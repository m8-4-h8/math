<Pravylo>
З двох чисел **більше те, що правіше** на координатній прямій. Тому:

- будь-яке додатне число більше за нуль, а нуль більший за будь-яке від'ємне;
- з двох від'ємних чисел **більше те, у якого модуль менший**.
</Pravylo>

:::note[Швидко нагадати]
- Від'ємне $<$ $0$ $<$ додатне: $-100 < 0 < 0{,}1$.
- Два від'ємні — порівнюємо модулі й «перевертаємо»: $|-7| > |-3|$, тому $-7 < -3$.
- Від'ємні дроби: $-\frac{1}{2} < -\frac{1}{3}$, бо $\frac{1}{2} > \frac{1}{3}$.
- Упорядкувати — спершу від'ємні (від найдальшого від нуля), потім нуль, потім додатні.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

  <span slot="rozviazok">$|-3{,}6| = 3{,}6$</span>

## Що це таке

**Спершу — з життя.** Узимку в Києві $-3$ °C, а в Харкові $-7$ °C. Де холодніше? У Харкові: $7$ градусів морозу — це більше
морозу, тобто **нижча** температура. Отже, $-7 < -3$, хоча $7 > 3$.

**Тепер — малюнок.** На прямій $-7$ лежить лівіше за $-3$, а лівіше — менше.

<KoordynatnaPriama min={-8} max={2} tochky={[{ nazva: 'A', x: -7 }, { nazva: 'B', x: -3 }]} modul />

**І лише тепер — правило.**

$$
a < 0 < b \qquad\qquad \text{якщо } a < 0 \text{ і } b < 0, \text{ то } a < b \iff |a| > |b|
$$

Тут $a$ — від'ємне число, $b$ — додатне. З двох від'ємних **менше** те, що **далі** від нуля, тобто з **більшим** модулем.

:::tip[Чому модулі «перевертаються»]
Від'ємне число — як борг. Хто винен $7$ грн, той бідніший за того, хто винен $3$ грн. Більший борг (модуль) — менше
число: $-7 < -3$.
:::

## Приклад

**Порівняй $-\frac{2}{3}$ і $-\frac{3}{4}$.**

1. Обидва числа від'ємні — порівнюємо модулі: $\frac{2}{3} = \frac{8}{12}$, $\;\frac{3}{4} = \frac{9}{12}$, тож $\frac{2}{3} < \frac{3}{4}$.
2. У $-\frac{2}{3}$ модуль менший, отже це число більше: $-\frac{2}{3} > -\frac{3}{4}$.
3. **Перевірка** на прямій: $-\frac{3}{4}$ далі від нуля (лівіше), ніж $-\frac{2}{3}$, тому менше ✓

## Спробуй сам

<Zavdannia vidpovid="−8, −3, 0, 5" pidkazka="Спершу від'ємні: з них менше те, що далі від нуля.">
  Запиши числа $-3$, $5$, $0$, $-8$ у порядку зростання (через кому).

  <span slot="rozviazok">На прямій зліва направо: $-8$, $-3$, $0$, $5$. Перевірка: $|-8| > |-3|$, тому $-8 < -3$ ✓; від'ємні менші за $0$, а $0 < 5$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Порівняли без мінуса.** $-7$ «виглядає» більшим за $-3$, бо $7 > 3$. Але з двох від'ємних більше те, що **ближче до нуля**:
$-7 < -3$. Як помітити: уяви температуру — $-7$ °C холодніше, ніж $-3$ °C.

**Від'ємний дріб і нуль.** $-0{,}1$ здається «майже нулем», але воно все одно менше за $0$ і менше за будь-яке додатне
число: $-0{,}1 < 0 < 0{,}01$.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="<" varianty={['>', '<', '=']} pidkazka="Яке з них ближче до нуля?">
  Порівняй: $-8 \;?\; -2$

  <span slot="rozviazok">$-2$ правіше на прямій, тому $-8 < -2$.</span>
</Zavdannia>

<Zavdannia vidpovid=">" varianty={['>', '<', '=']} pidkazka="Порівняй модулі: 3,5 і 3,6. У кого модуль менший, те й більше.">
  Порівняй: $-3{,}5 \;?\; -3{,}6$

  <span slot="rozviazok">$|-3{,}5| < |-3{,}6|$, тому $-3{,}5 > -3{,}6$.</span>
</Zavdannia>

<Zavdannia vidpovid=">" varianty={['>', '<', '=']} pidkazka="Будь-яке від'ємне число менше за нуль.">
  Порівняй: $0 \;?\; -0{,}1$

  <span slot="rozviazok">$-0{,}1$ — від'ємне, тому $0 > -0{,}1$.</span>
</Zavdannia>

<Zavdannia vidpovid="<" varianty={['>', '<', '=']} pidkazka="Порівняй модулі: 1/2 і 1/3.">
  Порівняй: $-\frac{1}{2} \;?\; -\frac{1}{3}$

  <span slot="rozviazok">$\frac{1}{2} > \frac{1}{3}$, тобто модуль $-\frac{1}{2}$ більший, тому $-\frac{1}{2} < -\frac{1}{3}$.</span>
</Zavdannia>

<Zavdannia vidpovid="−5" pidkazka="Ліворуч від −4,3 найближче ціле — яке?">
  Яке найбільше ціле число менше за $-4{,}3$?

  <span slot="rozviazok">Ліворуч від $-4{,}3$ найближче ціле — $-5$. Не $-4$: воно правіше, тобто більше за $-4{,}3$.</span>
</Zavdannia>

<Zavdannia vidpovid="4" pidkazka="Випиши: −2, −1, …">

  <span slot="rozviazok">$-2$, $-1$, $0$, $1$ — чотири числа.</span>
</Zavdannia>
