<Pravylo>
Щоб додати два від'ємні числа, **додай їхні модулі** й постав перед результатом знак **«−»**:
$\;-3 + (-5) = -(3 + 5) = -8$.

Сума від'ємних чисел — від'ємна. Додати нуль — нічого не змінити: $a + 0 = a$.
</Pravylo>

:::note[Швидко нагадати]
- Додати від'ємне — крок **ліворуч** на координатній прямій.
- Два від'ємні: модулі додаємо, знак «−»: $-6 + (-3) = -9$.
- Десяткові й звичайні дроби — так само: $-2{,}7 + (-4{,}5) = -7{,}2$; $\;-\frac{1}{3} + \left(-\frac{1}{6}\right) = -\frac{1}{2}$.
- Від'ємне число після «$+$» беремо в дужки: $-3 + (-5)$, а не $-3 + -5$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Модуль — з теми [Модуль числа](/math/6-klas/modul-chysla/).

<Zavdannia vidpovid="12" pidkazka="|−7| = 7, |−5| = 5.">
  Обчисли $|-7| + |-5|$.

  <span slot="rozviazok">$7 + 5 = 12$</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Тарас винен другові $3$ грн, а потім позичив у нього ще $5$ грн. Тепер борг — $8$ грн. Числами:
борг $-3$, ще борг $-5$, разом $-8$: $\;-3 + (-5) = -8$.

**Тепер — малюнок.** Стартуємо з $-3$ і додаємо $-5$ — стрибаємо на $5$ поділок **ліворуч**, ще далі від нуля:

<KoordynatnaPriama min={-9} max={2} strybok={{ vid: -3, na: -5 }} />

**І лише тепер — правило.**

$$
(-a) + (-b) = -(a + b) \qquad (a > 0,\ b > 0)
$$

Обидва доданки ведуть ліворуч, тому відстань до нуля — модуль — **збільшується**: $3 + 5 = 8$. А знак залишається «мінус».

:::tip[Навіщо дужки]
Два знаки поспіль не пишуть: $-3 + -5$ читається погано. Від'ємне число, що стоїть після знака дії, беруть у дужки: $-3 + (-5)$.
Перше число в дужки не беруть: $-3$ на початку — просто число.
:::

## Приклад

**Обчисли $-2{,}7 + (-4{,}5)$.**

1. Обидва доданки від'ємні — додаємо модулі: $2{,}7 + 4{,}5 = 7{,}2$.
2. Ставимо «мінус»: $-2{,}7 + (-4{,}5) = -7{,}2$.
3. **Перевірка** прикидкою: приблизно $-3 + (-4{,}5) = -7{,}5$ — близько до $-7{,}2$, і знак «мінус» ✓

## Спробуй сам

<Zavdannia vidpovid={['−1/2', '−0,5']} pidkazka="Додай модулі: 1/3 + 1/6, спільний знаменник 6.">
  Обчисли $-\frac{1}{3} + \left(-\frac{1}{6}\right)$.

  <span slot="rozviazok">$\frac{1}{3} + \frac{1}{6} = \frac{2}{6} + \frac{1}{6} = \frac{3}{6} = \frac{1}{2}$; відповідь $-\frac{1}{2}$. Перевірка: обидва доданки від'ємні — сума теж ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Забули мінус.** $-3 + (-5) = 8$ — неправильно: борги не стають заощадженнями. Сума двох від'ємних — від'ємна: $-8$.

**Відняли модулі.** $-3 + (-5) = -2$ — неправильно: модулі **віднімають**, коли знаки **різні**. Як помітити: обидва стрибки
ведуть ліворуч, отже, результат далі від нуля, ніж кожен доданок, — його модуль більший за $5$.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="−15" pidkazka="7 + 8, знак «−».">
  $-7 + (-8)$

  <span slot="rozviazok">$-(7 + 8) = -15$</span>
</Zavdannia>

<Zavdannia vidpovid="−40" pidkazka="24 + 16, знак «−».">
  $-24 + (-16)$

  <span slot="rozviazok">$-(24 + 16) = -40$</span>
</Zavdannia>

<Zavdannia vidpovid="−2,5" pidkazka="0,8 + 1,7, знак «−».">
  $-0{,}8 + (-1{,}7)$

  <span slot="rozviazok">$-(0{,}8 + 1{,}7) = -2{,}5$</span>
</Zavdannia>

<Zavdannia vidpovid="−1" pidkazka="3/4 + 1/4 = 1.">
  $-\frac{3}{4} + \left(-\frac{1}{4}\right)$

  <span slot="rozviazok">$-\left(\frac{3}{4} + \frac{1}{4}\right) = -1$</span>
</Zavdannia>

<Zavdannia vidpovid="−12" pidkazka="Додати нуль — нічого не змінити.">
  $-12 + 0$

  <span slot="rozviazok">$-12 + 0 = -12$</span>
</Zavdannia>

<Zavdannia vidpovid="−7" pidkazka="Зміни: −3 і −4. Додай їх до нуля.">
  Від $0$ °C температура спершу знизилася на $3°$, а потім ще на $4°$. Якою стала температура?

  <span slot="rozviazok">$0 + (-3) + (-4) = -7$ °C.</span>
</Zavdannia>
