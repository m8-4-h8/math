<Pravylo>
Для будь-яких раціональних чисел:

- $a + b = b + a$ — **переставна** властивість;
- $(a + b) + c = a + (b + c)$ — **сполучна** властивість;
- $a + 0 = a$ і $\;a + (-a) = 0$.

Тому доданки можна **переставляти й групувати** як зручно: протилежні — одразу дають нуль, решту — окремо додатні, окремо від'ємні.
</Pravylo>

:::note[Швидко нагадати]
- Протилежні доданки — закресли: $-17 + 5 + 17 = 5$.
- Додатні до додатних, від'ємні до від'ємних: $8 + (-3) + 2 + (-7) = 10 + (-10) = 0$.
- Зручні пари: $-2{,}7 + 4{,}5 + (-0{,}3) = (-2{,}7 + (-0{,}3)) + 4{,}5 = -3 + 4{,}5 = 1{,}5$.
- Переставляємо доданок **разом зі своїм знаком**.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Що це таке

**Спершу — з життя.** За тиждень Оля записувала зміни в гаманці: отримала $50$ грн, витратила $20$, отримала $30$, витратила $50$,
витратила $10$. Як змінилася сума? Можна рахувати по черзі, а можна хитріше: $50$ отримала й $50$ витратила — це нуль, а
$30$ отримала й $20 + 10$ витратила — теж нуль.

**Тепер — малюнок.** Зелені — додатні доданки, рожеві — від'ємні. Протилежні закреслено.

<ZnakoviDodanky dodanky={[50, -20, 30, -50, -10]} />

**І лише тепер — правило.**

$$
a + b = b + a \qquad (a + b) + c = a + (b + c) \qquad a + (-a) = 0
$$

Ці властивості ми знали для натуральних чисел. Вони справджуються й для від'ємних, тож суму можна рахувати в **будь-якому порядку**.

:::tip[Чому порядок не важливий]
Кожен доданок — стрибок по координатній прямій. Байдуже, у якому порядку стрибати: $5$ праворуч і $3$ ліворуч чи навпаки — опинишся
в тій самій точці, на $2$ праворуч від старту.
:::

## Приклад

**Обчисли зручно: $-23 + 48 + (-77) + 12$.**

1. Групуємо від'ємні: $-23 + (-77) = -100$ — кругле число.
2. Групуємо додатні: $48 + 12 = 60$.
3. Разом: $-100 + 60 = -40$.
4. **Перевірка** по черзі: $-23 + 48 = 25$; $\;25 + (-77) = -52$; $\;-52 + 12 = -40$ ✓

## Спробуй сам

<Zavdannia vidpovid="1,5" pidkazka="−2,7 і −0,3 разом дають −3.">
  Обчисли зручно: $-2{,}7 + 4{,}5 + (-0{,}3)$.

  <span slot="rozviazok">$(-2{,}7 + (-0{,}3)) + 4{,}5 = -3 + 4{,}5 = 1{,}5$. Перевірка по черзі: $-2{,}7 + 4{,}5 = 1{,}8$; $\;1{,}8 + (-0{,}3) = 1{,}5$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Переставили число без знака.** $-8 + 5 + 3$ — це **не** $8 + 5 - 3$. Знак належить доданку і переїжджає разом із ним:
$-8 + 5 + 3 = 5 + 3 + (-8) = 8 + (-8) = 0$.

**«Знищили» не протилежні числа.** $-7$ і $7$ разом — нуль, а $-7$ і $-7$ — ні: $-7 + (-7) = -14$. Протилежні — з **різними** знаками.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="5" pidkazka="−17 і 17 — протилежні.">
  $-17 + 5 + 17$

  <span slot="rozviazok">$-17 + 17 = 0$, залишається $5$.</span>
</Zavdannia>

<Zavdannia vidpovid="0" pidkazka="Додатні: 8 + 2. Від'ємні: −3 + (−7).">
  $8 + (-3) + 2 + (-7)$

  <span slot="rozviazok">$10 + (-10) = 0$</span>
</Zavdannia>

<Zavdannia vidpovid="−40" pidkazka="−23 + (−77) = −100.">
  $-23 + 48 + (-77) + 12$

  <span slot="rozviazok">$-100 + 60 = -40$</span>
</Zavdannia>

<Zavdannia vidpovid="−2" pidkazka="Згрупуй −3,6 і −1,4; 2,5 і 0,5.">
  $-3{,}6 + 2{,}5 + (-1{,}4) + 0{,}5$

  <span slot="rozviazok">$(-3{,}6 + (-1{,}4)) + (2{,}5 + 0{,}5) = -5 + 3 = -2$</span>
</Zavdannia>

<Zavdannia vidpovid="−1" pidkazka="Додай дроби з однаковими знаменниками: −3/7 + (−4/7).">
  $-\frac{3}{7} + \frac{5}{9} + \left(-\frac{4}{7}\right) + \left(-\frac{5}{9}\right)$

  <span slot="rozviazok">$\frac{5}{9} + \left(-\frac{5}{9}\right) = 0$; $\;-\frac{3}{7} + \left(-\frac{4}{7}\right) = -1$.</span>
</Zavdannia>

<Zavdannia vidpovid="−10" pidkazka="Пари: 1 + (−2) = −1. Скільки таких пар?">
  $1 + (-2) + 3 + (-4) + \ldots + 19 + (-20)$ — додатні непарні числа від $1$ до $19$ і від'ємні парні від $-2$ до $-20$.

  <span slot="rozviazok">Групуємо по два: $1 + (-2) = -1$, $\;3 + (-4) = -1$, … Пар — $10$, і десять доданків $-1$ разом дають $-10$.</span>
</Zavdannia>
