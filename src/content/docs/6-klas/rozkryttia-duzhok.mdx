<Pravylo>
**«+» перед дужками** — дужки й знак «+» перед ними прибираємо, знаки доданків **не змінюються**: $a + (b - c) = a + b - c$.

**«−» перед дужками** — дужки й знак «−» прибираємо, а знак **кожного** доданка в дужках змінюємо на протилежний:
$a - (b - c) = a - b + c$.
</Pravylo>

:::note[Швидко нагадати]
- $+(a - 3) = a - 3$ — знаки ті самі.
- $-(a - 3) = -a + 3$ — змінився знак **кожного** доданка.
- $-(-x - 5) = x + 5$.
- Зручно рахувати: $37 - (17 - 8) = 37 - 17 + 8 = 28$.
- Перший доданок у дужках без знака — це «плюс»: $-(a + b) = -a - b$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Віднімання — додавання протилежного, тема [Віднімання раціональних чисел](/math/6-klas/vidnimannia-ratsionalnykh-chysel/).

  $-8 - (-3)$

  <span slot="rozviazok">$-8 + 3 = -5$</span>

## Що це таке

**Спершу — з життя.** У гаманці $50$ грн. Ти купуєш сік за $20$ грн, а продавець дає знижку $5$ грн. Витрата — $(20 - 5)$ грн, і
лишається $50 - (20 - 5)$. Можна рахувати інакше: віддав $20$ грн і отримав назад $5$ — тобто $50 - 20 + 5 = 35$. Знижка в
дужках «віднімалася від витрати», а після розкриття дужок — **додається** до грошей.

**Тепер — малюнок.** Мінус перед дужками — як команда «зроби навпаки» для всіх, хто в дужках. Розкриймо $-(a - 5 + 2b)$:

<RozkryttiaDuzhok mnozhnyk={-1} dodanky={[{ k: 1, b: 'a' }, { k: -5 }, { k: 2, b: 'b' }]} />

А «плюс» перед дужками нічого не змінює:

<RozkryttiaDuzhok mnozhnyk={1} dodanky={[{ k: 1, b: 'a' }, { k: -5 }, { k: 2, b: 'b' }]} />

**І лише тепер — правило.**

$$
+(a - b + c) = a - b + c \qquad\qquad -(a - b + c) = -a + b - c
$$

:::tip[Чому мінус змінює всі знаки]
Відняти суму — означає відняти кожен доданок: $-(a + b) = -a + (-b) = -a - b$. А відняти від'ємне $-c$ — означає додати $c$.
Тому кожен доданок у дужках «перевертає» знак.
:::

## Приклад

**Обчисли зручно: $-4{,}7 - (2{,}6 - 4{,}7)$.**

1. Перед дужками «−»: змінюємо знак кожного доданка — $-4{,}7 - 2{,}6 + 4{,}7$.
2. Протилежні доданки $-4{,}7$ і $4{,}7$ дають $0$.
3. Залишається $-2{,}6$.
4. **Перевірка** без розкриття дужок: $2{,}6 - 4{,}7 = -2{,}1$; $\;-4{,}7 - (-2{,}1) = -4{,}7 + 2{,}1 = -2{,}6$ ✓

## Спробуй сам

<Zavdannia vidpovid="28" pidkazka="Розкрий дужки: 37 − 17 + 8.">
  Обчисли зручно: $37 - (17 - 8)$

  <span slot="rozviazok">$37 - 17 + 8 = 20 + 8 = 28$. Перевірка: $17 - 8 = 9$, $\;37 - 9 = 28$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Змінили знак лише першого доданка.** $-(2x - 5) = -2x - 5$ — неправильно: «мінус» перед дужками змінює знаки **усіх**
доданків, тож $-(2x - 5) = -2x + 5$. Як помітити: перевір при $x = 0$: $\;-(0 - 5) = 5$, а $-2 \cdot 0 - 5 = -5$ — не збіглося.

**Змінили знаки при «плюсі».** $a + (b - c) = a + b + c$ — неправильно: «плюс» перед дужками нічого не змінює.
:::

## Перевір себе

Впиши відповідь або вибери варіант. Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="−4 + y" varianty={['4 − y', '−4 + y', '−4 − y']} pidkazka="Мінус перед дужками змінює знак кожного доданка.">
  Розкрий дужки: $-(4 - y)$

  <span slot="rozviazok">$4$ стає $-4$, а $-y$ стає $+y$: $-4 + y$.</span>
</Zavdannia>

<Zavdannia vidpovid="a − b + 7" varianty={['a − b + 7', 'a + b − 7', 'a − b − 7']} pidkazka="Плюс перед дужками — знаки не змінюються.">
  Розкрий дужки: $a + (-b + 7)$

  <span slot="rozviazok">$a - b + 7$ — знаки в дужках залишилися.</span>
</Zavdannia>

<Zavdannia vidpovid="x + 5" varianty={['x + 5', '−x + 5', 'x − 5']} pidkazka="Змінюємо знак і в −x, і в −5.">
  Розкрий дужки: $-(-x - 5)$

  <span slot="rozviazok">$-x$ стає $x$, $-5$ стає $5$: $x + 5$.</span>
</Zavdannia>

<Zavdannia vidpovid="−6" pidkazka="Розкрий дужки: −15 − 6 + 15.">
  Обчисли зручно: $-15 - (6 - 15)$

  <span slot="rozviazok">$-15 - 6 + 15 = -6$ ($-15$ і $15$ — протилежні).</span>
</Zavdannia>

<Zavdannia vidpovid="10" pidkazka="Розкрий обидві дужки: 8,3 + 1,7 − 3,6 + 3,6.">
  Обчисли зручно: $(8{,}3 + 1{,}7) - (3{,}6 - 3{,}6)$

  <span slot="rozviazok">$8{,}3 + 1{,}7 - 3{,}6 + 3{,}6 = 10 + 0 = 10$.</span>
</Zavdannia>

<Zavdannia vidpovid="−12" pidkazka="Спершу розкрий дужки: a − b + 2 − a.">
  Знайди значення виразу $a - (b - 2 + a)$, якщо $b = 14$.

  <span slot="rozviazok">$a - b + 2 - a = -b + 2$; при $b = 14$: $-14 + 2 = -12$. Значення $a$ не потрібне!</span>
</Zavdannia>
