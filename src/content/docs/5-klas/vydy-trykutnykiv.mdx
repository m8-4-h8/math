<Pravylo>
  Трикутники розрізняють **за кутами** (гострокутний, прямокутний, тупокутний) і **за сторонами**
  (різносторонній, рівнобедрений, рівносторонній).
</Pravylo>

:::note[Швидко нагадати]
- За кутами: **гострокутний** — усі кути гострі, **прямокутний** — один кут $90°$, **тупокутний** — один кут тупий.
- За сторонами: **різносторонній** — усі різні, **рівнобедрений** — дві рівні, **рівносторонній** — усі три рівні.
- Сума кутів трикутника — $180°$, тому прямий чи тупий кут у ньому може бути лише **один**.
- Рівні сторони позначають рисочками, рівні кути — дугами, прямий кут — квадратиком.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Вид трикутника за кутами залежить від [видів кутів](/math/5-klas/vydy-kutiv/).

<Zavdannia vidpovid="тупий" varianty={['гострий', 'прямий', 'тупий']} pidkazka="Порівняй із 90°.">
  Кут $120°$ — якого виду?

  <span slot="rozviazok">$120° > 90°$ — тупий.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Дорожній знак «Увага!» — трикутник з однаковими сторонами. Шкільний косинець має прямий
кут. А дах казкового будиночка — трикутник з двома однаковими схилами.

**Тепер — малюнок.**

Рівні сторони на малюнку позначають однаковими **рисочками**, рівні кути — однаковими **дугами**, прямий
кут — **квадратиком**.

**І лише тепер — правило.** Кожен трикутник має дві «назви»: одну — за кутами, другу — за сторонами.

### За кутами

| Вид           | Які кути                                  |
| ------------- | ----------------------------------------- |
| гострокутний  | усі три кути [гострі](/math/5-klas/vydy-kutiv/) |
| прямокутний   | один кут прямий ($90°$)                   |
| тупокутний    | один кут тупий                            |

### За сторонами

| Вид            | Які сторони                                       |
| -------------- | ------------------------------------------------- |
| різносторонній | усі сторони різні                                 |
| рівнобедрений  | дві сторони рівні (бічні), третя — основа         |
| рівносторонній | усі три сторони рівні                             |

У рівнобедреного трикутника кути при основі рівні. У рівностороннього рівні всі кути.

:::tip[Чому прямий чи тупий кут — лише один]
Сума кутів будь-якого трикутника дорівнює $180°$. Два прямі кути вже дали б $90° + 90° = 180°$, і на третій
нічого не залишилось би. А два тупі — навіть більше за $180°$.
:::

## Приклад

**Два кути трикутника $50°$ і $60°$. Знайди третій кут і визнач вид трикутника за кутами.**

1. Сума кутів — $180°$. Відомі кути разом: $50° + 60° = 110°$.
2. Третій кут: $180° - 110° = 70°$.
3. Усі три кути ($50°$, $60°$, $70°$) менші за $90°$ — трикутник **гострокутний**.
4. **Перевірка:** $50° + 60° + 70° = 180°$ ✓

## Спробуй сам

<Zavdannia vidpovid="110" pidkazka="Сума кутів трикутника — 180°. Спершу додай відомі кути.">
  Два кути трикутника $30°$ і $40°$. Скільки градусів у третьому куті?

  <span slot="rozviazok">$30° + 40° = 70°$; $180° - 70° = 110°$ — тупий кут, тож трикутник тупокутний. Перевірка: $30° + 40° + 110° = 180°$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**«Прямокутний — коли прямий кут унизу».** Трикутник можна повернути як завгодно — вид від цього не зміниться. Як
помітити: шукай квадратик або приклади кутик аркуша до кожного кута.

**Рівносторонній — теж рівнобедрений.** У нього рівні не дві, а всі три сторони, тож умова «дві сторони рівні»
виконується. Але не навпаки: рівнобедрений трикутник зі сторонами $5$, $5$ і $8$ см — не рівносторонній.

**Два тупі кути.** Трикутника з кутами $100°$ і $95°$ не буває: $100° + 95° = 195°$ — уже більше за $180°$.
:::
