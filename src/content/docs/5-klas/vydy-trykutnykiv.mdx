Рівні сторони на малюнку позначають однаковими **рисочками**, рівні кути — однаковими **дугами**, прямий
кут — **квадратиком**.

## За кутами

| Вид           | Які кути                                  |
| ------------- | ----------------------------------------- |
| гострокутний  | усі три кути [гострі](/math/5-klas/vydy-kutiv/) |
| прямокутний   | один кут прямий ($90°$)                   |
| тупокутний    | один кут тупий                            |

## За сторонами

| Вид            | Які сторони                                       |
| -------------- | ------------------------------------------------- |
| різносторонній | усі сторони різні                                 |
| рівнобедрений  | дві сторони рівні (бічні), третя — основа         |
| рівносторонній | усі три сторони рівні                             |

У рівнобедреного трикутника кути при основі рівні. У рівностороннього рівні всі кути.

:::note[Цікаво]
Сума кутів будь-якого трикутника дорівнює $180°$. Тому прямий або тупий кут у трикутнику може бути тільки
**один**: два прямі кути вже дали б $180°$, і на третій нічого не залишилось би.
:::

## Перевір себе

1. Сторони трикутника $5$ см, $5$ см і $8$ см. Який це трикутник за сторонами?
2. Кути трикутника $90°$, $60°$ і $30°$. Який це трикутник за кутами?
3. Периметр рівностороннього трикутника $27$ см. Знайди його сторону.

<details>
<summary>Відповіді</summary>

1. Рівнобедрений (дві сторони по $5$ см).
2. Прямокутний.
3. $27 : 3 = 9$ см.

</details>
