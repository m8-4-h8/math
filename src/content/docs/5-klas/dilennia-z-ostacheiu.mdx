## Що таке остача

Не кожне число ділиться націло. Коли [ділимо цукерки порівну](/math/4-klas/dilennia-porivnu/), іноді кілька
залишається — на всіх уже не вистачає. Це і є **остача**.

<Tsukerky tsukerky={13} liudy={4} />

## Які остачі бувають

Якби остача була рівна дільнику або більша, з неї можна було б дати кожному ще по одній. Тому при діленні на
$6$ остача може бути тільки від $0$ до $5$:

<Ostachi dilnyk={6} dilene={20} />

## Перевірка

$$
\text{ділене} = \text{дільник} \cdot \text{неповна частка} + \text{остача}
$$

Для $20 : 6 = 3 \text{ (ост. } 2)$: $6 \cdot 3 + 2 = 20$ ✓

:::caution[Не плутай]
Остача вийшла **рівна дільнику або більша** — значить, частку взяли замалу.
$20 : 6 = 2 \text{ (ост. } 8)$ — неправильно, бо $8 > 6$. Збільшуємо частку на $1$: $20 : 6 = 3 \text{ (ост. } 2)$.
:::

Великі числа з остачею ділять [кутом](/math/4-klas/dilennia-kutom/) — остача залишається внизу після останнього
кроку.

## Перевір себе

1. $47 : 5$
2. $30 : 7$
3. Які остачі можуть бути при діленні на $4$?
4. Чи правильно: $35 : 8 = 3 \text{ (ост. } 11)$?

<details>
<summary>Відповіді</summary>

1. $9 \text{ (ост. } 2)$, бо $5 \cdot 9 + 2 = 47$
2. $4 \text{ (ост. } 2)$, бо $7 \cdot 4 + 2 = 30$
3. $0, 1, 2, 3$
4. Ні: $11 > 8$. Правильно $35 : 8 = 4 \text{ (ост. } 3)$

</details>
