## Що це таке

Мама з'їла $\frac{2}{8}$ піци, тато — $\frac{3}{8}$. Разом — $5$ шматочків по одній восьмій, тобто $\frac{5}{8}$.
Шматочки однакові, тому рахуємо їх, як яблука: $2 + 3 = 5$ восьмих.

$$
\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c} \qquad\qquad \frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}
$$

## Мішані числа

**Додаємо окремо цілі частини і окремо дробові.** Якщо дробова частина вийшла неправильним дробом —
виділяємо з неї цілу і додаємо до цілих.

$$
2\frac{3}{5} + 1\frac{4}{5} = 3\frac{7}{5} = 4\frac{2}{5}
$$

**Віднімаємо так само.** А якщо дробова частина зменшуваного менша — «позичаємо» одну цілу:
$5\frac{1}{4} - 2\frac{3}{4} = 4\frac{5}{4} - 2\frac{3}{4} = 2\frac{2}{4}$.

Від цілого числа віднімаємо так: $1 = \frac{7}{7}$, тому $1 - \frac{3}{7} = \frac{4}{7}$; $3 - \frac{2}{5} = 2\frac{5}{5} - \frac{2}{5} = 2\frac{3}{5}$.

## Приклад

**Від стрічки завдовжки $4\frac{1}{6}$ м відрізали $1\frac{5}{6}$ м. Скільки залишилось?**

1. $\frac{1}{6} < \frac{5}{6}$ — позичаємо одну цілу: $4\frac{1}{6} = 3\frac{7}{6}$.
2. Цілі: $3 - 1 = 2$; дробові: $\frac{7}{6} - \frac{5}{6} = \frac{2}{6}$.
3. Залишилось $2\frac{2}{6}$ м.
4. **Перевірка** додаванням: $2\frac{2}{6} + 1\frac{5}{6} = 3\frac{7}{6} = 4\frac{1}{6}$ ✓

:::caution[Не плутай]
**Знаменники не додаємо!** $\frac{1}{4} + \frac{2}{4} = \frac{3}{4}$, а не $\frac{3}{8}$. Знаменник — це розмір
шматочка, він не змінюється, коли шматочки збираємо разом.
:::
