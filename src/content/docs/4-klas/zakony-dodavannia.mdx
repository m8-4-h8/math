Від **переставляння** доданків сума не змінюється. Доданки можна **групувати** як зручно.

## Переставний і сполучний закони

Уяви три відрізки стрічки: $38$ см, $27$ см і $62$ см. Як їх не переставляй, разом вийде та сама довжина.
А якщо спершу скласти $38$ і $62$ — вийде рівно $100$, і далі рахувати легко.

<SmuzhkaSumy chastyny={[38, 27, 62]} poriadok={[0, 2, 1]} razom={[0, 2]} />

$$
a + b = b + a \qquad\qquad (a + b) + c = a + (b + c)
$$

Перша рівність — **переставний** закон, друга — **сполучний**: доданки можна об'єднувати в групи
(«сполучати») як завгодно. І ще: $a + 0 = a$ — додавання нуля число не змінює.

## Віднімання суми і від суми

**Відняти суму** — те саме, що відняти доданки по одному:

$$
a - (b + c) = a - b - c
$$

$500 - (200 + 87) = 500 - 200 - 87 = 300 - 87 = 213$.

**Відняти число від суми** — можна відняти його від того доданка, від якого зручніше:

$$
(a + b) - c = (a - c) + b
$$

$(70 + 46) - 30 = (70 - 30) + 46 = 40 + 46 = 86$.

## Приклад

**Обчисли зручно: $246 + 178 + 54$.**

1. Шукаємо пару з круглою сумою: $246 + 54 = 300$ (одиниці $6 + 4 = 10$).
2. Переставляємо: $246 + 54 + 178 = 300 + 178 = 478$.
3. **Перевірка** по порядку: $246 + 178 = 424$, $424 + 54 = 478$ ✓

:::caution[Не плутай]
**Віднімання переставляти не можна!** $10 - 3 \ne 3 - 10$.

І коли розкриваєш дужки після мінуса — **обидва** числа віднімаються:
$85 - (25 + 30) = 85 - 25 - 30 = 30$, а не $85 - 25 + 30$.
:::
