## Чому малюнок допомагає

Текст задачі легко прочитати, але важко «побачити». Коли задачу намальовано, кожне число має своє місце, а
знак питання показує, що треба знайти. Наприклад: **«Пішохід ішов 3 год зі швидкістю 4 км/год. Скільки він
пройшов?»** — це просто три однакові шматочки дороги:

## П'ять кроків

1. **Прочитай** задачу до кінця. Що відбувається? Хто рухається, хто працює, що порівнюють?
2. **Випиши**, що відомо, а що треба знайти.
3. **Обери малюнок** за типом задачі (таблиця нижче).
4. **Підпиши** на малюнку всі числа, а невідоме — «?».
5. **Розв'яжи** і **перевір**: підстав відповідь у малюнок — чи все сходиться? ✓

## Який малюнок обрати

| Якщо в задачі… | Малюємо | Тема |
| --- | --- | --- |
| швидкість, відстань, час, «їхав», «ішов», «назустріч» | **лінію** — дорогу, поділену на години | [Рух — це лінія](/math/vizualizatsiia-zadach/rukh-yak-liniia/) |
| «за годину робить», «зібрав», «виготовив», «разом» | **кошики** — кожна година окремий кошик | [Робота — це кошики](/math/vizualizatsiia-zadach/robota-yak-koshyky/) |
| «на … більше», «на … менше», «у … разів» | **дві смужки** одна під одною | [Порівняння — це смужки](/math/vizualizatsiia-zadach/porivniannia-smuzhkamy/) |
| «разом», «утричі більше», «поділили так, що…» | **однакові клітинки**-частини | [Частини — це клітинки](/math/vizualizatsiia-zadach/chastyny-klitynkamy/) |
| ціна, кількість, вартість | **кошики**: один кошик = одна покупка за ціною | [Робота — це кошики](/math/vizualizatsiia-zadach/robota-yak-koshyky/#ціна-кількість-вартість) |
| частина від цілого, $\frac{2}{5}$ від числа | **смужку-шоколадку**, поділену на рівні частини | [Дріб від числа](/math/5-klas/drib-vid-chysla/) |
| довжина, ширина, площа | **прямокутник у клітинку** | [Площа і периметр](/math/5-klas/ploshcha-i-perymetr/) |

:::caution[Не плутай]
Малюнок — не картина для краси. Не треба малювати машину з колесами: досить **точки й стрілки**. Головне —
щоб однакові величини мали однаковий розмір, а невідоме було позначене «?».
:::
