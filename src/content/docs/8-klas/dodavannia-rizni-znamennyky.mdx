<Pravylo nazva="Різні знаменники">
Щоб додати (відняти) дроби з **різними знаменниками**:

1. розклади знаменники на множники;
2. знайди **спільний знаменник** — вираз, у якому є всі множники кожного знаменника;
3. знайди **додатковий множник** кожного дробу — чого бракує його знаменнику до спільного;
4. помнож чисельник на додатковий множник і додай (відніми) дроби з однаковими знаменниками;
5. скороти відповідь, якщо можна.

$$
\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}
$$
</Pravylo>

:::note[Швидко нагадати]
- $\frac{2}{x} + \frac{3}{y} = \frac{2y + 3x}{xy}$.
- $\frac{1}{3a} + \frac{1}{6a}$: спільний знаменник $6a$, тож $\frac{2 + 1}{6a} = \frac{3}{6a} = \frac{1}{2a}$.
- Многочлени — спершу на множники:
  $\frac{1}{x - 2} - \frac{4}{x^2 - 4} = \frac{x + 2 - 4}{(x - 2)(x + 2)} = \frac{1}{x + 2}$.
- Ціле — це дріб зі знаменником $1$: $a + \frac{1}{a} = \frac{a^2 + 1}{a}$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Числові дроби з різними знаменниками ми додавали в [6 класі](/math/6-klas/dodavannia-drobiv-z-riznymy-znamennykamy/).
Перевір, чи пам'ятаєш:

<Zavdannia vidpovid="5/12" pidkazka="Спільний знаменник 12: додаткові множники 3 і 2.">
  Обчисли $\frac{1}{4} + \frac{1}{6}$. Запиши відповідь через риску, наприклад 2/5.

  <span slot="rozviazok">$\frac{1 \cdot 3}{12} + \frac{1 \cdot 2}{12} = \frac{3 + 2}{12} = \frac{5}{12}$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Ти фарбуєш паркан за $4$ години, а друг — за $6$. За одну годину ти пофарбуєш $\frac{1}{4}$
паркана, друг — $\frac{1}{6}$. Скільки разом? Чверті й шості — різні «шматочки», їх не можна просто скласти. Ріжемо
обидва на однакові дрібніші — дванадцяті: $\frac{1}{4} = \frac{3}{12}$, $\frac{1}{6} = \frac{2}{12}$. Разом
$\frac{5}{12}$ паркана.

<SpilnyiZnamennyk a={[1, 4]} b={[1, 6]} dia="+" />

А якщо ти фарбуєш за $x$ годин, а друг — за $y$? Разом за годину — $\frac{1}{x} + \frac{1}{y}$. Спільний знаменник —
$xy$, додаткові множники — $y$ і $x$: $\frac{1}{x} + \frac{1}{y} = \frac{y + x}{xy}$.

**Тепер — малюнок.** Над кожним дробом — його додатковий множник: чого бракує знаменнику до спільного. На нього
множимо **і чисельник**, бо за [основною властивістю дробу](/math/8-klas/osnovna-vlastyvist-drobu/) множити можна
лише чисельник і знаменник разом.

<DodavanniaVyraziv drobi={[{ ch: '3', zn: ['2', 'a'] }, { ch: '5', zn: ['3', 'a'] }]} dia="+" chysRazom="19" />

Знаменники-многочлени спершу розкладаємо на множники: $x^2 - 4 = (x - 2)(x + 2)$. Спільний знаменник — $x^2 - 4$,
а не добуток $(x - 2)(x^2 - 4)$: так менше рахувати.

<DodavanniaVyraziv drobi={[{ ch: '1', zn: ['(x − 2)'] }, { ch: '4', zn: ['(x − 2)', '(x + 2)'] }]} dia="−" chysRazom="x − 2" rezultat={['1', 'x + 2']} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Який спільний знаменник брати]
Добуток знаменників **завжди** підходить, але часто він громіздкий. Найпростіший спільний знаменник — як НСК для
чисел: кожен множник беремо стільки разів, скільки він трапляється в знаменнику, де його найбільше. Для $6a^2$ і
$4ab$ це $12a^2b$, а не $24a^3b$.
:::

## Приклад

**Спрости вираз $\frac{2}{x} - \frac{x - 4}{x^2 - 2x}$.**

1. Розкладаємо знаменники: $x$ і $x^2 - 2x = x(x - 2)$.
2. Спільний знаменник — $x(x - 2)$. Додаткові множники: для першого дробу $x - 2$, для другого — $1$.
3. Віднімаємо, другий чисельник — у дужках: $\frac{2(x - 2) - (x - 4)}{x(x - 2)}$.
4. Чисельник: $2x - 4 - x + 4 = x$. Скорочуємо: $\frac{x}{x(x - 2)} = \frac{1}{x - 2}$.
5. **Перевірка:** візьмемо $x = 3$. Початковий вираз:
   $\frac{2}{3} - \frac{3 - 4}{9 - 6} = \frac{2}{3} + \frac{1}{3} = 1$. Відповідь: $\frac{1}{3 - 2} = 1$ ✓

## Спробуй сам

<Zavdannia vidpovid="1" pidkazka="a² + 3a = a(a + 3). Додатковий множник першого дробу — a + 3.">
  Спрости вираз $\frac{4}{a} - \frac{12}{a^2 + 3a}$ і знайди його значення при $a = 1$.

  <span slot="rozviazok">$\frac{4(a + 3) - 12}{a(a + 3)} = \frac{4a}{a(a + 3)} = \frac{4}{a + 3}$. При $a = 1$: $\frac{4}{4} = 1$. Перевірка: $\frac{4}{1} - \frac{12}{1 + 3} = 4 - 3 = 1$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Не додаємо окремо чисельники й знаменники.** $\frac{1}{x} + \frac{1}{y} \ne \frac{2}{x + y}$. Перевір при
$x = y = 1$: $1 + 1 = 2$, а $\frac{2}{1 + 1} = 1$.

**Чисельник теж множимо.** Якщо знаменник $2a$ домножили до $6a$, чисельник множимо на той самий множник $3$:
$\frac{3}{2a} = \frac{9}{6a}$, а не $\frac{3}{6a}$.

**Мінус перед дробом — дужки.** $\frac{2}{x} - \frac{x - 4}{x(x - 2)} = \frac{2(x - 2) - (x - 4)}{x(x - 2)}$. Без
дужок вийде $-x - 4$ замість $-x + 4$.
:::

## Перевір себе

Обери варіант або впиши відповідь. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="12" pidkazka="НСК(4; 6) = 12.">
  Найпростіший спільний знаменник дробів $\frac{1}{4x}$ і $\frac{1}{6x}$ — це $kx$. Знайди $k$.

  <span slot="rozviazok">$4x = 2 \cdot 2 \cdot x$, $6x = 2 \cdot 3 \cdot x$. Спільний знаменник $2 \cdot 2 \cdot 3 \cdot x = 12x$, $k = 12$.</span>
</Zavdannia>

<Zavdannia vidpovid="x" varianty={['x', 'x − 1', '5']} pidkazka="Чого бракує знаменнику x − 1 до x(x − 1)?">
  Спільний знаменник — $x(x - 1)$. Який додатковий множник у дробу $\frac{5}{x - 1}$?

  <span slot="rozviazok">$x(x - 1) : (x - 1) = x$ — бракує множника $x$.</span>
</Zavdannia>

<Zavdannia vidpovid="7" pidkazka="Спільний знаменник 6x. Не забудь скоротити.">
  Яке число треба вписати в квадратик: $\frac{5}{2x} - \frac{1}{6x} = \frac{\square}{3x}$?

  <span slot="rozviazok">$\frac{15}{6x} - \frac{1}{6x} = \frac{14}{6x} = \frac{7}{3x}$.</span>
</Zavdannia>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Перевір на числах: x = 1, y = 1.">
  Чи правильна рівність $\frac{1}{x} + \frac{1}{y} = \frac{2}{x + y}$?

  <span slot="rozviazok">Ні. При $x = y = 1$: ліворуч $1 + 1 = 2$, праворуч $\frac{2}{2} = 1$. Правильно: $\frac{1}{x} + \frac{1}{y} = \frac{x + y}{xy}$.</span>
</Zavdannia>

<Zavdannia vidpovid="3" pidkazka="x² − 9 = (x − 3)(x + 3). Додатковий множник першого дробу — x + 3.">
  Спрости вираз $\frac{3}{x - 3} - \frac{18}{x^2 - 9}$ і знайди його значення при $x = -2$.

  <span slot="rozviazok">$\frac{3(x + 3) - 18}{(x - 3)(x + 3)} = \frac{3x - 9}{(x - 3)(x + 3)} = \frac{3}{x + 3}$. При $x = -2$: $\frac{3}{1} = 3$. Перевірка: $\frac{3}{-5} - \frac{18}{4 - 9} = -0{,}6 + 3{,}6 = 3$ ✓</span>
</Zavdannia>

<Zavdannia vidpovid="5" pidkazka="x = x²/x. Віднімаємо весь чисельник x² − 1.">
  Спрости вираз $x - \frac{x^2 - 1}{x}$ і знайди його значення при $x = 0{,}2$.

  <span slot="rozviazok">$\frac{x^2 - (x^2 - 1)}{x} = \frac{1}{x}$. При $x = 0{,}2$: $1 : 0{,}2 = 5$.</span>
</Zavdannia>

<Zavdannia vidpovid="1/2" pidkazka="За 1 год перша труба наповнює 1/x басейну, друга — 1/(2x).">
  Перша труба наповнює басейн за $x$ год, друга — за $2x$ год. Яку частину басейну вони наповнять разом за $1$ год,
  якщо $x = 3$? Запиши дріб через риску.

  <span slot="rozviazok">$\frac{1}{x} + \frac{1}{2x} = \frac{2 + 1}{2x} = \frac{3}{2x}$. При $x = 3$: $\frac{3}{6} = \frac{1}{2}$.</span>
</Zavdannia>

### Змішане повторення

<Zavdannia vidpovid="7" pidkazka="Знаменники однакові. Чи не виноситься 7 за дужки?">
  Спрости вираз $\frac{7a}{a - 1} - \frac{7}{a - 1}$. Яке число вийшло?

  <span slot="rozviazok">[Однакові знаменники](/math/8-klas/dodavannia-odnakovi-znamennyky/): $\frac{7a - 7}{a - 1} = \frac{7(a - 1)}{a - 1} = 7$.</span>
</Zavdannia>

<Zavdannia vidpovid="120" pidkazka="Нехай кути 2x, 3x, 3x, 4x. Їхня сума — 360°.">
  Кути чотирикутника відносяться як $2 : 3 : 3 : 4$. Знайди найбільший кут (у градусах).

  <span slot="rozviazok">[Сума кутів чотирикутника](/math/8-klas/chotyrykutnyk/): $2 + 3 + 3 + 4 = 12$ частин, одна частина $360^\circ : 12 = 30^\circ$, найбільший кут $4 \cdot 30^\circ = 120^\circ$.</span>
</Zavdannia>
