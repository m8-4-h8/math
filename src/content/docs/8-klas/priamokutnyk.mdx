<Pravylo nazva="Прямокутник">
**Прямокутник** — паралелограм, у якого **всі кути прямі**.

Прямокутник має всі властивості паралелограма і ще одну: **діагоналі прямокутника рівні**. Тому
$AO = BO = CO = DO$.

**Ознаки прямокутника.** Паралелограм є прямокутником, якщо:

1. один його кут **прямий**;
2. його **діагоналі рівні**.
</Pravylo>

:::note[Швидко нагадати]
- $AC = 10$ — тоді $BD = 10$ і $AO = BO = CO = DO = 5$.
- Трикутники $AOB$ і $AOD$ рівнобедрені: $\angle OAB = \angle OBA$, $\angle OAD = \angle ODA$.
- $\angle BAC = 25^\circ$ — тоді $\angle CAD = 90^\circ - 25^\circ = 65^\circ$.
- У паралелограма досить **одного** прямого кута — решта теж прямі.
- Рівні діагоналі — ознака прямокутника лише для **паралелограма**. Діагоналі прямокутника не перпендикулярні.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

У задачах про прямокутник діагональ ділить його на два прямокутні трикутники. Пригадай
[властивість прямокутного трикутника](/math/7-klas/vlastyvosti-priamokutnoho-trykutnyka/):

<Zavdannia vidpovid="55" pidkazka="Сума гострих кутів прямокутного трикутника — 90°.">
  Один гострий кут прямокутного трикутника дорівнює $35^\circ$. Знайди другий гострий кут (у градусах).

  <span slot="rozviazok">$90^\circ - 35^\circ = 55^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Будівельники розмічають фундамент будинку шнурами. Як перевірити, що кути прямі, якщо великого
кутника немає? Спершу роблять протилежні сторони рівними — виходить паралелограм. А потім міряють рулеткою **дві
діагоналі**: якщо вони рівні, кути прямі. Так само «діагональ екрана» телевізора вказують однією: у прямокутника
обидві діагоналі однакові.

**Тепер — малюнок.** Прямокутник — це паралелограм, тож протилежні сторони рівні, а діагоналі діляться навпіл. А ще всі
чотири половинки діагоналей рівні (однакові рисочки):

<Ryad pidpys="Ліворуч — чотири прямі кути, протилежні сторони рівні. Праворуч — AO = BO = CO = DO.">
  <Chotyrykutnyk forma="priamokutnyk" priami={[0, 1, 2, 3]} rysky={[1, 2, 1, 2]} ramka={false} />
  <Chotyrykutnyk forma="priamokutnyk" peretyn="O" ryskyDiahonalei={[1, 1]} priami={[0]} ramka={false} />
</Ryad>

Звідси головний наслідок для задач: трикутники $AOB$, $BOC$, $COD$, $AOD$ — **рівнобедрені**, а кути при їхніх основах
рівні.

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому діагоналі рівні]
Розглянемо трикутники $ABD$ і $DCA$. У них $AB = DC$ (протилежні сторони), $AD$ — спільна сторона,
$\angle BAD = \angle CDA = 90^\circ$. Трикутники рівні за [першою ознакою](/math/7-klas/persha-oznaka-rivnosti/),
тож $BD = CA$. Навпаки, якщо в паралелограмі $AC = BD$, ті самі трикутники рівні за трьома сторонами, тому
$\angle A = \angle D$. А разом ці сусідні кути дають $180^\circ$, отже, кожен дорівнює $90^\circ$ — це ознака 2.
:::

## Приклад

**Діагоналі прямокутника $ABCD$ перетинаються в точці $O$, $\angle CAD = 32^\circ$. Знайди кути $AOD$ і $AOB$.**

1. $AO = DO$ — половини рівних діагоналей. Отже, трикутник $AOD$ рівнобедрений: $\angle ODA = \angle OAD = 32^\circ$.
2. $\angle AOD = 180^\circ - 32^\circ - 32^\circ = 116^\circ$.
3. Кути $AOB$ і $AOD$ суміжні: $\angle AOB = 180^\circ - 116^\circ = 64^\circ$.
4. **Перевірка:** $\angle OAB = 90^\circ - 32^\circ = 58^\circ$, і в рівнобедреному трикутнику $AOB$
   $180^\circ - 58^\circ - 58^\circ = 64^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="6" pidkazka="AO = BO = 6. Який трикутник AOB, якщо кут при вершині 60°?">
  Діагональ прямокутника $ABCD$ дорівнює $12$ см, а кут $AOB$ між діагоналями — $60^\circ$. Знайди $AB$ (у см).

  <span slot="rozviazok">$AO = BO = 12 : 2 = 6$ см. Трикутник $AOB$ рівнобедрений, кути при основі $(180^\circ - 60^\circ) : 2 = 60^\circ$, тож він рівносторонній: $AB = 6$ см. Перевірка: $60^\circ + 60^\circ + 60^\circ = 180^\circ$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Рівні діагоналі — ще не прямокутник.** Ознака діє лише для паралелограма. У рівнобічної трапеції діагоналі теж
рівні:

<Chotyrykutnyk tochky={[[0, 1], [0.35, 0], [1.25, 0], [1.6, 1]]} diahonali={[[0, 2], [1, 3]]} shtrykh={false} pidpys="AC = BD, але ABCD — трапеція: BC і AD різної довжини." />

**Діагоналі прямокутника не перпендикулярні** і не ділять його кути навпіл: $\angle BAC \ne \angle CAD$, якщо сторони
різні. Так буває лише в квадрата.

**Квадрат — теж прямокутник.** Усі його кути прямі, тож усе сказане тут стосується і квадрата.
:::

## Перевір себе

Обери варіант або впиши відповідь. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="7" pidkazka="Діагоналі прямокутника рівні й діляться навпіл.">
  Діагоналі прямокутника $ABCD$ перетинаються в точці $O$, $AC = 14$ см. Знайди $BO$ (у см).

  <span slot="rozviazok">$BD = AC = 14$ см, $BO = 14 : 2 = 7$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="65" pidkazka="Кут A прямокутника — 90°, діагональ AC ділить його на дві частини.">
  У прямокутнику $ABCD$ $\angle BAC = 25^\circ$. Знайди $\angle CAD$ (у градусах).

  <span slot="rozviazok">$\angle CAD = 90^\circ - 25^\circ = 65^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="так" varianty={['так', 'ні']} pidkazka="Це ознака 2.">
  Діагоналі паралелограма рівні. Чи є він прямокутником?

  <span slot="rozviazok">Так. Паралелограм з рівними діагоналями — прямокутник (ознака 2).</span>
</Zavdannia>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Згадай рівнобічну трапецію.">
  Діагоналі чотирикутника рівні. Чи обов'язково він прямокутник?

  <span slot="rozviazok">Ні. Ознака діє лише для паралелограма, а в рівнобічної трапеції діагоналі теж рівні.</span>
</Zavdannia>

<Zavdannia vidpovid="55" pidkazka="Трикутник AOB рівнобедрений: AO = BO.">
  Діагоналі прямокутника $ABCD$ перетинаються в точці $O$, $\angle AOB = 70^\circ$. Знайди $\angle OAB$ (у градусах).

  <span slot="rozviazok">$AO = BO$, тож кути при основі $AB$ рівні: $(180^\circ - 70^\circ) : 2 = 55^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="16" pidkazka="AO і BO — половини діагоналей.">
  Діагональ прямокутника $ABCD$ дорівнює $10$ см, $AB = 6$ см. Знайди периметр трикутника $AOB$ (у см).

  <span slot="rozviazok">$AO = BO = 10 : 2 = 5$ см. $P = 5 + 5 + 6 = 16$ см.</span>
</Zavdannia>

<Chotyrykutnyk forma="priamokutnyk" vidrizok={[0, 1, 0.625, 'K']} priami={[0]} />

<Zavdannia vidpovid="26" pidkazka="Бісектриса прямого кута утворює кут 45°. Який тоді трикутник ABK?">
  Бісектриса кута $A$ прямокутника $ABCD$ перетинає сторону $BC$ у точці $K$, $BK = 5$ см, $KC = 3$ см. Знайди периметр
  прямокутника (у см).

  <span slot="rozviazok">$\angle BAK = 90^\circ : 2 = 45^\circ$, а в прямокутному трикутнику $ABK$ тоді й $\angle BKA = 45^\circ$. Отже, $AB = BK = 5$ см. $BC = 5 + 3 = 8$ см, $P = 2 \cdot (5 + 8) = 26$ см.</span>
</Zavdannia>

### Змішане повторення

<Zavdannia vidpovid="7" pidkazka="Дія 1 — додавання в дужках, спільний знаменник ab.">
  Спрости вираз $\left(\frac{1}{a} + \frac{1}{b}\right) \cdot ab$ і знайди його значення при $a = 3$, $b = 4$.

  <span slot="rozviazok">[Тотожні перетворення](/math/8-klas/totozhni-peretvorennia/): $\frac{b + a}{ab} \cdot ab = a + b$, при $a = 3$, $b = 4$: $7$.</span>
</Zavdannia>

<Zavdannia vidpovid="120" pidkazka="Сусідні кути паралелограма разом 180°: 3 частини.">
  Кути $A$ і $B$ паралелограма $ABCD$ відносяться як $1 : 2$. Знайди $\angle B$ (у градусах).

  <span slot="rozviazok">[Паралелограм](/math/8-klas/paralelohram/): $180^\circ : 3 = 60^\circ$, $\angle B = 2 \cdot 60^\circ = 120^\circ$.</span>
</Zavdannia>
