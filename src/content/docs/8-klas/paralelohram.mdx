<Pravylo nazva="Паралелограм">
**Паралелограм** — чотирикутник, у якого **протилежні сторони попарно паралельні**: $AB \parallel CD$,
$BC \parallel AD$.

**Властивості паралелограма:**

1. протилежні **сторони рівні**: $AB = CD$, $BC = AD$;
2. протилежні **кути рівні**: $\angle A = \angle C$, $\angle B = \angle D$;
3. кути, прилеглі до однієї сторони, разом дають $180^\circ$: $\angle A + \angle B = 180^\circ$;
4. **діагоналі** точкою перетину **діляться навпіл**: $AO = OC$, $BO = OD$.

Периметр: $P = 2(a + b)$, де $a$ і $b$ — сусідні сторони.
</Pravylo>

:::note[Швидко нагадати]
- Один кут $70^\circ$ — усі кути $70^\circ$, $110^\circ$, $70^\circ$, $110^\circ$.
- Сторони $5$ см і $8$ см — периметр $2 \cdot (5 + 8) = 26$ см.
- Діагональ $AC = 10$ — тоді $AO = OC = 5$.
- Діагоналі паралелограма **не обов'язково рівні** і **не ділять кути навпіл**.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Усі властивості паралелограма виходять з [властивостей паралельних прямих](/math/7-klas/vlastyvosti-paralelnykh/).
Перевір, чи пам'ятаєш:

<Zavdannia vidpovid="115" pidkazka="Внутрішні односторонні кути при паралельних прямих разом дають 180°.">
  $a \parallel b$, $c$ — січна. Один із внутрішніх односторонніх кутів дорівнює $65^\circ$. Знайди другий.

  <span slot="rozviazok">$180^\circ - 65^\circ = 115^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Поклади стопку зошитів і штовхни верхні вбік — бічна грань стопки з прямокутника стане
«перекошеною». Верх і низ лишилися паралельними, ліва й права сторони — теж. Так само складаються розсувні ворота
й лампа на шарнірах: ланки «перекошуються», але протилежні сторони весь час паралельні. Така фігура — **паралелограм**.

**Тепер — малюнок.** Однакові стрілочки позначають паралельні сторони:

<Chotyrykutnyk forma="paralelohram" strilky={[1, 2, 1, 2]} />

Що з цього випливає? Однакові рисочки — рівні відрізки:

<Ryad pidpys="Ліворуч — рівні протилежні сторони й кути. Праворуч — діагоналі діляться точкою O навпіл.">
  <Chotyrykutnyk forma="paralelohram" rysky={[1, 2, 1, 2]} kuty={['70°', '110°', '70°', '110°']} ramka={false} />
  <Chotyrykutnyk forma="paralelohram" peretyn="O" ryskyDiahonalei={[1, 2]} ramka={false} />
</Ryad>

- Протилежні сторони рівні: $AB = CD$, $BC = AD$ (одна й дві рисочки).
- Протилежні кути рівні: $\angle A = \angle C = 70^\circ$, $\angle B = \angle D = 110^\circ$.
- Сусідні кути $A$ і $B$ — внутрішні односторонні при паралельних $BC$ і $AD$ та січній $AB$, тому
  $70^\circ + 110^\circ = 180^\circ$.
- Діагоналі $AC$ і $BD$ перетинаються в точці $O$, яка ділить кожну з них навпіл: $AO = OC$, $BO = OD$. Самі діагоналі
  різної довжини.

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому це правда]
Діагональ $AC$ ділить паралелограм на трикутники $ABC$ і $CDA$. У них $AC$ — спільна сторона,
$\angle BAC = \angle DCA$ і $\angle BCA = \angle DAC$ — внутрішні різносторонні кути при паралельних прямих. За
[другою ознакою](/math/7-klas/druha-oznaka-rivnosti/) трикутники рівні, отже, $AB = CD$, $BC = AD$ і
$\angle B = \angle D$. Так само, з рівних трикутників $AOB$ і $COD$, виходить $AO = OC$ і $BO = OD$.
:::

## Приклад

**У паралелограмі $ABCD$ кут $A$ на $40^\circ$ менший за кут $B$. Знайди всі кути.**

1. Кути $A$ і $B$ прилеглі до сторони $AB$, тож $\angle A + \angle B = 180^\circ$.
2. Нехай $\angle A = x$, тоді $\angle B = x + 40^\circ$: $x + x + 40^\circ = 180^\circ$, $2x = 140^\circ$, $x = 70^\circ$.
3. $\angle A = \angle C = 70^\circ$, $\angle B = \angle D = 70^\circ + 40^\circ = 110^\circ$.
4. **Перевірка:** $70^\circ + 110^\circ + 70^\circ + 110^\circ = 360^\circ$ і $110^\circ - 70^\circ = 40^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="11" pidkazka="Периметр — це дві суми сусідніх сторін: a + b = 36 : 2.">
  Периметр паралелограма $36$ см, а одна його сторона на $4$ см більша за іншу. Знайди більшу сторону (у см).

  <span slot="rozviazok">Дві сусідні сторони разом $36 : 2 = 18$ см. Нехай менша $x$, тоді $x + x + 4 = 18$, $x = 7$, більша $7 + 4 = 11$ см. Перевірка: $2 \cdot (7 + 11) = 36$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Діагоналі паралелограма не обов'язково рівні.** Рівні вони лише в прямокутника. На малюнку $AC$ помітно довша за
$BD$. Навпіл ділиться **кожна** діагональ, але половинки різних діагоналей різні: $AO \ne BO$.

**Діагональ не ділить кут навпіл.** $\angle BAC$ і $\angle CAD$ — різні кути (так буває лише в ромба).

**Сусідні кути — не рівні, а разом $180^\circ$.** Якщо $\angle A = 50^\circ$, то протилежний $\angle C = 50^\circ$,
а сусідній $\angle B = 130^\circ$.

**Периметр — $2(a + b)$, а не $a + b$.** Сторін чотири: по дві кожної довжини.
:::

## Перевір себе

Обери варіант або впиши відповідь. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="65" pidkazka="C — протилежний до A.">
  У паралелограмі $ABCD$ $\angle A = 65^\circ$. Знайди $\angle C$ (у градусах).

  <span slot="rozviazok">Протилежні кути рівні: $\angle C = \angle A = 65^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="115" pidkazka="B — сусідній з A: разом 180°.">
  У паралелограмі $ABCD$ $\angle A = 65^\circ$. Знайди $\angle B$ (у градусах).

  <span slot="rozviazok">$\angle A + \angle B = 180^\circ$, тож $\angle B = 180^\circ - 65^\circ = 115^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="38" pidkazka="P = 2(a + b).">
  Сусідні сторони паралелограма — $7$ см і $12$ см. Знайди його периметр (у см).

  <span slot="rozviazok">$P = 2 \cdot (7 + 12) = 38$ см.</span>
</Zavdannia>

<Chotyrykutnyk forma="paralelohram" peretyn="O" pidpysyDiahonalei={['9', undefined, '?', undefined]} />

<Zavdannia vidpovid="5" pidkazka="Точка O ділить діагональ BD навпіл.">
  Діагоналі паралелограма $ABCD$ — $AC = 18$ і $BD = 10$ — перетинаються в точці $O$. Знайди $BO$.

  <span slot="rozviazok">$O$ — середина $BD$: $BO = 10 : 2 = 5$. Довжина $AC$ тут не потрібна ($AO = 9$).</span>
</Zavdannia>

<Zavdannia vidpovid="105" pidkazka="Два сусідні кути разом дають 180°, а тут 150° — отже, це протилежні кути.">
  Сума двох кутів паралелограма дорівнює $150^\circ$. Знайди більший кут паралелограма (у градусах).

  <span slot="rozviazok">Сусідні кути разом $180^\circ$, тож це протилежні кути, по $150^\circ : 2 = 75^\circ$. Більший кут $180^\circ - 75^\circ = 105^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Подивися на малюнок: AC і BD однакові?">
  Чи правильно, що діагоналі будь-якого паралелограма рівні?

  <span slot="rozviazok">Ні. Діагоналі діляться навпіл, але рівні лише в прямокутника.</span>
</Zavdannia>

<Chotyrykutnyk forma="paralelohram" vidrizok={[0, 1, 0.6, 'K']} storony={['6', undefined, undefined, '10']} />

<Zavdannia vidpovid="4" pidkazka="∠BKA = ∠KAD як внутрішні різносторонні. Який тоді трикутник ABK?">
  Бісектриса кута $A$ паралелограма $ABCD$ перетинає сторону $BC$ у точці $K$. $AB = 6$, $AD = 10$. Знайди $KC$.

  <span slot="rozviazok">$\angle BKA = \angle KAD$ (внутрішні різносторонні при $BC \parallel AD$), а $\angle KAD = \angle BAK$ — бо $AK$ бісектриса. Отже, трикутник $ABK$ рівнобедрений: $BK = AB = 6$. $BC = AD = 10$, тож $KC = 10 - 6 = 4$.</span>
</Zavdannia>

### Змішане повторення

<Zavdannia vidpovid="2" pidkazka="Знаменники однакові — додай чисельники.">
  Спрости вираз $\frac{3}{x} + \frac{5}{x}$ і знайди його значення при $x = 4$.

  <span slot="rozviazok">[Однакові знаменники](/math/8-klas/dodavannia-odnakovi-znamennyky/): $\frac{8}{x}$, при $x = 4$: $8 : 4 = 2$.</span>
</Zavdannia>

<Zavdannia vidpovid="70" pidkazka="Кути при основі рівнобедреного трикутника рівні.">
  Кут при вершині рівнобедреного трикутника дорівнює $40^\circ$. Знайди кут при основі (у градусах).

  <span slot="rozviazok">[Рівнобедрений трикутник](/math/7-klas/rivnobedrenyi-trykutnyk/): $(180^\circ - 40^\circ) : 2 = 70^\circ$.</span>
</Zavdannia>
