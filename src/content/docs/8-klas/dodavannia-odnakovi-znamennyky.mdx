<Pravylo nazva="Однакові знаменники">
Щоб додати (відняти) дроби з **однаковими знаменниками**, додаємо (віднімаємо) їхні **чисельники**, а знаменник
залишаємо **той самий**:

$$
\frac{a}{c} + \frac{b}{c} = \frac{a + b}{c}, \qquad \frac{a}{c} - \frac{b}{c} = \frac{a - b}{c}.
$$

Від'ємник-многочлен беремо **в дужки**. Відповідь, якщо можна, **скорочуємо**.
</Pravylo>

:::note[Швидко нагадати]
- $\frac{3x}{y} + \frac{2x}{y} = \frac{5x}{y}$ — знаменник не змінюється.
- Мінус перед дробом стосується всього чисельника:
  $\frac{5a + 1}{a} - \frac{2a - 3}{a} = \frac{5a + 1 - 2a + 3}{a} = \frac{3a + 4}{a}$.
- Протилежні знаменники: $\frac{b}{2 - x} = -\frac{b}{x - 2}$ — міняємо знак перед дробом, і знаменники стають
  однаковими.
- Після дії — скорочуємо: $\frac{x}{x - 3} - \frac{3}{x - 3} = \frac{x - 3}{x - 3} = 1$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Звичайні дроби з однаковими знаменниками ми додавали в [5 класі](/math/5-klas/dodavannia-drobiv/). Перевір, чи
пам'ятаєш:

<Zavdannia vidpovid="5/12" pidkazka="Знаменник лишається 12, віднімаємо лише чисельники.">
  Обчисли $\frac{7}{12} - \frac{2}{12}$. Запиши відповідь через риску, наприклад 2/5.

  <span slot="rozviazok">$\frac{7 - 2}{12} = \frac{5}{12}$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** $3$ яблука і $2$ яблука — це $5$ яблук: додаємо кількість, а «яблука» не змінюються.
Так само $3$ сьомих і $2$ сьомих — це $5$ сьомих: $\frac{3}{7} + \frac{2}{7} = \frac{5}{7}$. Знаменник — це «назва»
частинок, він не додається.

Зі змінною — те саме. $\frac{3}{x}$ — це $3$ частинки по $\frac{1}{x}$. Турист пройшов $3$ км, а потім ще $5$ км з
тією самою швидкістю $v$ км/год. Час — $\frac{3}{v} + \frac{5}{v} = \frac{8}{v}$ год: однаково, рахувати дві ділянки
окремо чи весь шлях $8$ км одразу.

**Тепер — малюнок.** Віднімаємо дріб, у якого чисельник — многочлен. Його беремо в дужки, бо віднімаємо **весь**:

<DodavanniaVyraziv drobi={[{ ch: '5x + 1', zn: ['x'] }, { ch: '2x − 3', zn: ['x'] }]} dia="−" chysRazom="3x + 4" />

Відповідь часто вдається скоротити. Тут чисельник — різниця квадратів: $x^2 - 9 = (x - 3)(x + 3)$:

<DodavanniaVyraziv drobi={[{ ch: 'x²', zn: ['(x − 3)'] }, { ch: '9', zn: ['(x − 3)'] }]} dia="−" rezultat={['x + 3', '1']} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому це правда]
Ділити на $c$ — те саме, що множити на $\frac{1}{c}$. Тому
$\frac{a}{c} + \frac{b}{c} = a \cdot \frac{1}{c} + b \cdot \frac{1}{c} = (a + b) \cdot \frac{1}{c} = \frac{a + b}{c}$ —
це просто [розподільна властивість](/math/7-klas/vynesennia-za-duzhky/): спільний множник $\frac{1}{c}$ виносимо за
дужки.
:::

**Протилежні знаменники.** $x - 2$ і $2 - x$ — не однакові, а протилежні: $2 - x = -(x - 2)$. Мінус переносимо перед
дріб, і знаменники стають однаковими:

$$
\frac{7}{x - 2} + \frac{3}{2 - x} = \frac{7}{x - 2} - \frac{3}{x - 2} = \frac{4}{x - 2}.
$$

## Приклад

**Спрости вираз $\frac{4a + 3}{a^2 - 1} - \frac{3a + 2}{a^2 - 1}$.**

1. Знаменники однакові — віднімаємо чисельники, від'ємник беремо в дужки: $\frac{4a + 3 - (3a + 2)}{a^2 - 1}$.
2. Розкриваємо дужки — знаки в них змінюються: $4a + 3 - 3a - 2 = a + 1$.
3. Скорочуємо: $\frac{a + 1}{a^2 - 1} = \frac{a + 1}{(a - 1)(a + 1)} = \frac{1}{a - 1}$.
4. **Перевірка:** візьмемо $a = 3$. Початковий вираз: $\frac{15}{8} - \frac{11}{8} = \frac{4}{8} = \frac{1}{2}$.
   Відповідь: $\frac{1}{3 - 1} = \frac{1}{2}$ ✓

## Спробуй сам

<Zavdannia vidpovid="3" pidkazka="Додай чисельники: 2x + 5 + x + 7. Чи не ділиться результат на x + 4?">
  Спрости вираз $\frac{2x + 5}{x + 4} + \frac{x + 7}{x + 4}$. Яке число вийшло?

  <span slot="rozviazok">$\frac{2x + 5 + x + 7}{x + 4} = \frac{3x + 12}{x + 4} = \frac{3(x + 4)}{x + 4} = 3$. Перевірка при $x = 1$: $\frac{7}{5} + \frac{8}{5} = \frac{15}{5} = 3$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Знаменники не додаємо.** $\frac{a}{x} + \frac{b}{x} \ne \frac{a + b}{2x}$. Перевір на числах:
$\frac{1}{5} + \frac{1}{5} = \frac{2}{5}$, а не $\frac{2}{10}$.

**Мінус стосується всього чисельника.** $\frac{5x}{y} - \frac{x - 2}{y} = \frac{5x - x + 2}{y}$, а не
$\frac{5x - x - 2}{y}$. Щоб не забути — пиши від'ємник у дужках.

**Протилежні знаменники — ще не однакові.** $\frac{3}{x - 1} + \frac{2}{1 - x} = \frac{3 - 2}{x - 1} = \frac{1}{x - 1}$,
а не $\frac{5}{x - 1}$. Перевір при $x = 2$: $3 + \frac{2}{-1} = 1$.
:::

## Перевір себе

Обери варіант або впиши відповідь. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="7" pidkazka="Знаменник той самий — додай чисельники 3x і 4x.">
  Яке число треба вписати в квадратик: $\frac{3x}{y} + \frac{4x}{y} = \frac{\square x}{y}$?

  <span slot="rozviazok">$\frac{3x + 4x}{y} = \frac{7x}{y}$.</span>
</Zavdannia>

<Zavdannia vidpovid="4" pidkazka="Спершу спрости: 9a − 2a.">
  Спрости вираз $\frac{9a}{b} - \frac{2a}{b}$ і знайди його значення при $a = 4$, $b = 7$.

  <span slot="rozviazok">$\frac{9a - 2a}{b} = \frac{7a}{b} = \frac{7 \cdot 4}{7} = 4$.</span>
</Zavdannia>

<Zavdannia vidpovid="2" pidkazka="Від'ємник 3m + 2 візьми в дужки.">
  Спрости вираз $\frac{5m + 2}{m} - \frac{3m + 2}{m}$. Яке число вийшло?

  <span slot="rozviazok">$\frac{5m + 2 - (3m + 2)}{m} = \frac{5m + 2 - 3m - 2}{m} = \frac{2m}{m} = 2$.</span>
</Zavdannia>

<Zavdannia vidpovid="4x + 5" varianty={['4x − 3', '4x + 5', '8x − 3']} pidkazka="Мінус перед дробом змінює знаки обох членів 2x − 4.">
  Який чисельник отримаємо: $\frac{6x + 1}{x} - \frac{2x - 4}{x}$?

  <span slot="rozviazok">$6x + 1 - (2x - 4) = 6x + 1 - 2x + 4 = 4x + 5$.</span>
</Zavdannia>

<Zavdannia vidpovid="5" pidkazka="5 − a = −(a − 5), тож другий дріб віднімаємо.">
  Знайди значення виразу $\frac{8}{a - 5} + \frac{3}{5 - a}$ при $a = 6$.

  <span slot="rozviazok">$\frac{8}{a - 5} - \frac{3}{a - 5} = \frac{5}{a - 5}$. При $a = 6$: $\frac{5}{1} = 5$. Перевірка: $\frac{8}{1} + \frac{3}{-1} = 8 - 3 = 5$ ✓</span>
</Zavdannia>

<Zavdannia vidpovid="100" pidkazka="x² − 16 = (x − 4)(x + 4).">
  Спрости вираз $\frac{x^2}{x - 4} - \frac{16}{x - 4}$ і знайди його значення при $x = 96$.

  <span slot="rozviazok">$\frac{x^2 - 16}{x - 4} = \frac{(x - 4)(x + 4)}{x - 4} = x + 4 = 96 + 4 = 100$.</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="Час = відстань : швидкість. Додай два дроби зі знаменником v.">
  Турист пройшов $14$ км лісом і $10$ км полем з однаковою швидкістю $v$ км/год. Скільки годин він ішов, якщо
  $v = 4$?

  <span slot="rozviazok">$\frac{14}{v} + \frac{10}{v} = \frac{24}{v}$. При $v = 4$: $24 : 4 = 6$ год.</span>
</Zavdannia>

### Змішане повторення

<Zavdannia vidpovid="40" pidkazka="x² − 25 = (x − 5)(x + 5).">
  Скороти дріб $\frac{x^2 - 25}{x + 5}$ і знайди його значення при $x = 45$.

  <span slot="rozviazok">[Скорочення дробів](/math/8-klas/osnovna-vlastyvist-drobu/): $\frac{(x - 5)(x + 5)}{x + 5} = x - 5 = 45 - 5 = 40$.</span>
</Zavdannia>

<Zavdannia vidpovid="85" pidkazka="Сума кутів чотирикутника — 360°.">
  Три кути чотирикутника — $90^\circ$, $85^\circ$ і $100^\circ$. Знайди четвертий кут (у градусах).

  <span slot="rozviazok">[Сума кутів чотирикутника](/math/8-klas/chotyrykutnyk/): $360^\circ - 90^\circ - 85^\circ - 100^\circ = 85^\circ$.</span>
</Zavdannia>
