<Pravylo nazva="Центральні та вписані кути">
**Центральний кут** — кут з вершиною в **центрі** кола. Градусна міра дуги дорівнює центральному куту, що на неї
спирається.

**Вписаний кут** — кут з вершиною **на колі**, сторони якого перетинають коло. Він дорівнює **половині**
центрального кута, що спирається на ту саму дугу:

$$
\angle ACB = \frac{1}{2} \angle AOB.
$$

**Наслідки:** вписані кути, що спираються на ту саму дугу, **рівні**; вписаний кут, що спирається на **діаметр**,
— **прямий**.
</Pravylo>

:::note[Швидко нагадати]
- $\angle AOB = 100^\circ$ — тоді дуга $AB = 100^\circ$, а вписаний $\angle ACB = 100^\circ : 2 = 50^\circ$.
- Вписаний кут $35^\circ$ — центральний на ту саму дугу $2 \cdot 35^\circ = 70^\circ$.
- Спирається на діаметр (півколо, $180^\circ$) — $180^\circ : 2 = 90^\circ$.
- Усе коло — $360^\circ$: якщо одна дуга $AB$ дорівнює $100^\circ$, то друга — $260^\circ$.
- Вписаний кут спирається на дугу, що лежить **між його сторонами** (не на ту, де вершина).

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Радіуси кола рівні, тож трикутник $AOB$ — [рівнобедрений](/math/7-klas/rivnobedrenyi-trykutnyk/). Перевір, чи
пам'ятаєш:

<Zavdannia vidpovid="55" pidkazka="Кути при основі рівні, а сума кутів трикутника — 180°.">
  Кут при вершині рівнобедреного трикутника $70^\circ$. Знайди кут при основі (у градусах).

  <span slot="rozviazok">$(180^\circ - 70^\circ) : 2 = 55^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** У театрі сцена — це відрізок $AB$. Глядач у центрі зали бачить її під одним кутом, а глядачі
на краю, що сидять по дузі кола, — під кутом удвічі меншим. І цікаво: **усі** глядачі на цій дузі бачать сцену під
**однаковим** кутом, хоч би де сиділи.

**Тепер — малюнок.** Кут $AOB$ — центральний: вершина в центрі. Він спирається на дугу $AB$ (зелена) — і дуга має
стільки ж градусів, $100^\circ$. Кут $ACB$ — вписаний: вершина $C$ на колі. Він спирається на ту саму дугу й
дорівнює половині: $50^\circ$.

<KoloElementy naKoli={{ A: 220, B: 320, C: 90 }} vidrizky={[{ a: 'O', b: 'A' }, { a: 'O', b: 'B' }, { a: 'C', b: 'A' }, { a: 'C', b: 'B' }]} kuty={[{ v: 'O', a: 'A', b: 'B', pidpys: '100°' }, { v: 'C', a: 'A', b: 'B', pidpys: '50°', r: 30 }]} dugy={[{ a: 'A', b: 'B', pidpys: '100°' }]} />

Пересуньмо вершину по дузі — у точки $C$, $D$, $E$. Кути $ACB$, $ADB$, $AEB$ спираються на ту саму зелену дугу,
тож усі рівні (однакові дужки):

<KoloElementy tsentr="" naKoli={{ A: 220, B: 320, C: 60, D: 115, E: 160 }} vidrizky={[{ a: 'C', b: 'A' }, { a: 'C', b: 'B' }, { a: 'D', b: 'A' }, { a: 'D', b: 'B' }, { a: 'E', b: 'A' }, { a: 'E', b: 'B' }]} kuty={[{ v: 'C', a: 'A', b: 'B', n: 1, r: 24 }, { v: 'D', a: 'A', b: 'B', n: 1, r: 24 }, { v: 'E', a: 'A', b: 'B', n: 1, r: 24 }]} dugy={[{ a: 'A', b: 'B' }]} />

А якщо $AB$ — діаметр, дуга — це півколо, $180^\circ$. Вписаний кут — половина: $90^\circ$.

<KoloElementy naKoli={{ A: 180, B: 0, C: 125 }} vidrizky={[{ a: 'A', b: 'B' }, { a: 'C', b: 'A' }, { a: 'C', b: 'B' }]} priamiKuty={[['C', 'A', 'B']]} dugy={[{ a: 'A', b: 'B', pidpys: '180°' }]} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому вписаний кут — половина центрального]
Візьмімо випадок, коли сторона $CB$ проходить через центр $O$. Трикутник $AOC$ рівнобедрений ($OA = OC$ —
радіуси), тож $\angle OAC = \angle OCA$. Кут $AOB$ — зовнішній кут цього трикутника, він дорівнює сумі двох
внутрішніх, не суміжних з ним: $\angle AOB = \angle OAC + \angle OCA = 2 \angle ACB$. Інші випадки зводяться до
цього, якщо провести діаметр через $C$.
:::

## Приклад

**$A$, $B$, $C$ — точки на колі з центром $O$, вписаний кут $ACB = 40^\circ$. Знайди кут $OAB$.**

1. Центральний кут на ту саму дугу вдвічі більший: $\angle AOB = 2 \cdot 40^\circ = 80^\circ$.
2. $OA = OB$ — радіуси, тож трикутник $AOB$ рівнобедрений, кути при основі $AB$ рівні.
3. $\angle OAB = (180^\circ - 80^\circ) : 2 = 50^\circ$.
4. **Перевірка:** $80^\circ + 50^\circ + 50^\circ = 180^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="65" pidkazka="Спершу знайди центральний кут AOB: він удвічі більший за вписаний.">
  $A$, $B$, $C$ — точки на колі з центром $O$, вписаний кут $ACB = 25^\circ$. Знайди кут $OAB$ (у градусах).

  <span slot="rozviazok">$\angle AOB = 2 \cdot 25^\circ = 50^\circ$. Трикутник $AOB$ рівнобедрений: $\angle OAB = (180^\circ - 50^\circ) : 2 = 65^\circ$. Перевірка: $50^\circ + 65^\circ + 65^\circ = 180^\circ$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Вписаний — половина, а не рівний.** «Центральний $100^\circ$, тож і вписаний $100^\circ$» — помилка. Як помітити:
вершина вписаного кута далі від дуги, ніж центр, і бачить її під меншим кутом — **удвічі** меншим.

**Множити чи ділити на 2?** Від центрального до вписаного — **ділимо**, від вписаного до центрального — **множимо**.
Центральний кут завжди більший.

**Яка дуга?** Вписаний кут спирається на дугу **між своїми сторонами**, а не на ту, де лежить вершина. Якщо дуга
$AB = 100^\circ$, а вершина $D$ лежить саме на ній, то кут $ADB$ спирається на іншу дугу: $(360^\circ - 100^\circ) :
2 = 130^\circ$.

**Кут на діаметр — $90^\circ$, а не $180^\circ$.** $180^\circ$ — це дуга (півколо), а вписаний кут — її половина.
:::

## Перевір себе

Обери варіант або впиши відповідь. За кожну правильну відповідь — зірочка ⭐

  <span slot="rozviazok">$\angle ACB = 140^\circ : 2 = 70^\circ$.</span>

<Zavdannia vidpovid="64" pidkazka="Центральний кут удвічі більший за вписаний.">

  <span slot="rozviazok">$2 \cdot 32^\circ = 64^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="40°" varianty={['40°', '80°', '160°']} pidkazka="Градусна міра дуги дорівнює центральному куту, а вписаний — половина.">
  Дуга $AB$ дорівнює $80^\circ$. Чому дорівнює вписаний кут, що спирається на цю дугу?

  <span slot="rozviazok">$80^\circ : 2 = 40^\circ$. $80^\circ$ — центральний кут, а $160^\circ$ — подвоєна дуга.</span>
</Zavdannia>

<Zavdannia vidpovid="55" pidkazka="Кут C спирається на діаметр AB.">
  $AB$ — діаметр кола, $C$ — точка на колі, $\angle CAB = 35^\circ$. Знайди $\angle CBA$ (у градусах).

  <span slot="rozviazok">$\angle ACB = 90^\circ$ (спирається на діаметр), тож $\angle CBA = 180^\circ - 90^\circ - 35^\circ = 55^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="47" pidkazka="Обидва кути спираються на ту саму дугу AB.">
  Точки $C$ і $D$ лежать на колі по один бік від хорди $AB$, $\angle ACB = 47^\circ$. Знайди $\angle ADB$ (у градусах).

  <span slot="rozviazok">Вписані кути, що спираються на ту саму дугу, рівні: $\angle ADB = 47^\circ$.</span>
</Zavdannia>

<KoloElementy naKoli={{ A: 220, B: 320, D: 295 }} vidrizky={[{ a: 'D', b: 'A' }, { a: 'D', b: 'B' }]} kuty={[{ v: 'D', a: 'A', b: 'B', pidpys: '?', r: 18 }]} dugy={[{ a: 'A', b: 'B', pidpys: '100°', t: 0.25 }]} />

<Zavdannia vidpovid="130" pidkazka="Точка D лежить на дузі 100°. На яку дугу тоді спирається кут ADB?">
  Дуга $AB$ дорівнює $100^\circ$, точка $D$ лежить на цій дузі. Знайди $\angle ADB$ (у градусах).

  <span slot="rozviazok">Кут $ADB$ спирається на іншу дугу: $360^\circ - 100^\circ = 260^\circ$. Тож $\angle ADB = 260^\circ : 2 = 130^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="80" pidkazka="Знайди дуги: 2x + 3x + 4x = 360°. Кожен кут трикутника — половина дуги навпроти.">
  Вершини трикутника ділять описане коло на три дуги, що відносяться як $2 : 3 : 4$. Знайди найбільший кут
  трикутника (у градусах).

  <span slot="rozviazok">$9x = 360^\circ$, $x = 40^\circ$, дуги $80^\circ$, $120^\circ$, $160^\circ$. Кути — їх половини: $40^\circ$, $60^\circ$, $80^\circ$. Перевірка: $40^\circ + 60^\circ + 80^\circ = 180^\circ$ ✓</span>
</Zavdannia>
