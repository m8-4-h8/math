<Pravylo nazva="Трапеція">
**Трапеція** — чотирикутник, у якого **дві сторони паралельні**, а дві інші — **не паралельні**. Паралельні сторони —
**основи**, непаралельні — **бічні сторони**.

- Кути, прилеглі до бічної сторони, разом дають $180^\circ$: $\angle A + \angle B = 180^\circ$.
- **Рівнобічна** трапеція ($AB = CD$): кути при кожній основі рівні, діагоналі рівні.
- **Прямокутна** трапеція: одна бічна сторона перпендикулярна до основ.
</Pravylo>

:::note[Швидко нагадати]
- $AD \parallel BC$, $\angle A = 70^\circ$ — тоді $\angle B = 180^\circ - 70^\circ = 110^\circ$.
- Рівнобічна, $\angle A = 65^\circ$ — тоді $\angle D = 65^\circ$, $\angle B = \angle C = 115^\circ$.
- Паралелограм — **не** трапеція: у трапеції паралельна лише одна пара сторін.
- У рівнобічній трапеції висота з $B$ відтинає на більшій основі $AH = (AD - BC) : 2$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Кути трапеції рахують через [властивості паралельних прямих](/math/7-klas/vlastyvosti-paralelnykh/). Перевір, чи
пам'ятаєш:

<Zavdannia vidpovid="110" pidkazka="Сума односторонніх кутів при паралельних прямих — 180°.">
  Прямі $a$ і $b$ паралельні, січна утворює з ними односторонні кути. Один з них $70^\circ$. Знайди другий (у
  градусах).

  <span slot="rozviazok">Односторонні кути при паралельних прямих разом дають $180^\circ$: $180^\circ - 70^\circ = 110^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Подивись збоку на відро чи склянку: верхній і нижній краї паралельні, а стінки сходяться
донизу. Переріз насипу під дорогою, абажур, сумка-«трапеція» — усе це трапеції. Дві сторони йдуть паралельно, як
рейки, а дві інші — ні.

**Тепер — малюнок.** Стрілочки показують паралельні сторони — основи $AD$ і $BC$. Бічні сторони $AB$ і $CD$ не
паралельні:

<Chotyrykutnyk forma="trapetsiia" strilky={[0, 1, 0, 1]} storony={['бічна сторона', 'основа', 'бічна сторона', 'основа']} W={380} />

У **рівнобічної** трапеції бічні сторони рівні (рисочки), тож вона симетрична: кути при основі $AD$ рівні, при
основі $BC$ — теж, а діагоналі однакові:

<Chotyrykutnyk forma="rivnobichna" strilky={[0, 1, 0, 1]} rysky={[1, 0, 1, 0]} diahonali={[[0, 2], [1, 3]]} shtrykh={false} />

У **прямокутної** трапеції бічна сторона $AB$ перпендикулярна до основ — два прямі кути:

<Chotyrykutnyk forma="priamokutna" strilky={[0, 1, 0, 1]} priami={[0, 1]} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому кути при бічній стороні дають 180°]
$AD \parallel BC$, а $AB$ — січна. Кути $A$ і $B$ — односторонні, тож разом $180^\circ$. Так само $\angle C + \angle D =
180^\circ$. А от $\angle A$ і $\angle D$ (при одній основі) у довільній трапеції ніяк не пов'язані.
:::

## Приклад

**$ABCD$ — рівнобічна трапеція з основами $AD$ і $BC$, $\angle A = 64^\circ$. Знайди решту кутів.**

<Chotyrykutnyk forma="rivnobichna" strilky={[0, 1, 0, 1]} rysky={[1, 0, 1, 0]} kuty={['64°', '?', '?', '?']} />

1. Кути при основі рівнобічної трапеції рівні: $\angle D = \angle A = 64^\circ$.
2. Кути при бічній стороні $AB$ разом $180^\circ$: $\angle B = 180^\circ - 64^\circ = 116^\circ$.
3. $\angle C = \angle B = 116^\circ$ — кути при основі $BC$.
4. **Перевірка:** сума кутів чотирикутника $64^\circ + 116^\circ + 116^\circ + 64^\circ = 360^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="55" pidkazka="Спершу знайди ∠A: він прилеглий до тієї самої бічної сторони, що й ∠B.">
  $ABCD$ — рівнобічна трапеція з основами $AD$ і $BC$, $\angle B = 125^\circ$. Знайди $\angle D$ (у градусах).

  <span slot="rozviazok">$\angle A = 180^\circ - 125^\circ = 55^\circ$, а $\angle D = \angle A = 55^\circ$. Перевірка: $55^\circ + 125^\circ + 125^\circ + 55^\circ = 360^\circ$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Паралелограм — не трапеція.** У трапеції паралельна **лише одна** пара сторін. Якщо паралельні обидві пари — це
паралелограм.

**Основи не обов'язково «знизу і зверху».** Поверни трапецію — вона лишиться трапецією. Основи — це паралельні
сторони, де б вони не лежали.

**Які кути разом $180^\circ$?** Прилеглі до **бічної** сторони ($\angle A$ і $\angle B$). Не кути при основі
($\angle A$ і $\angle D$) і не протилежні ($\angle A$ і $\angle C$).

**Рівні кути при основі — лише в рівнобічної.** У довільної трапеції $\angle A$ і $\angle D$ можуть бути будь-якими.
:::

## Перевір себе

Обери варіант або впиши відповідь. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="130" pidkazka="∠A і ∠B прилеглі до бічної сторони AB.">
  $ABCD$ — трапеція з основами $AD$ і $BC$, $\angle A = 50^\circ$. Знайди $\angle B$ (у градусах).

  <span slot="rozviazok">$\angle B = 180^\circ - 50^\circ = 130^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="72" pidkazka="У рівнобічній трапеції ∠B = ∠C.">
  $ABCD$ — рівнобічна трапеція з основами $AD$ і $BC$, $\angle C = 108^\circ$. Знайди $\angle A$ (у градусах).

  <span slot="rozviazok">$\angle B = \angle C = 108^\circ$, тож $\angle A = 180^\circ - 108^\circ = 72^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Скільки пар паралельних сторін у трапеції?">
  Чи є паралелограм трапецією?

  <span slot="rozviazok">Ні. У паралелограма паралельні обидві пари сторін, а в трапеції — лише одна.</span>
</Zavdannia>

<Zavdannia vidpovid="128" pidkazka="∠C і ∠D прилеглі до бічної сторони CD.">
  $ABCD$ — прямокутна трапеція з основами $AD$ і $BC$, $\angle A = 90^\circ$, $\angle D = 52^\circ$. Знайди $\angle C$
  (у градусах).

  <span slot="rozviazok">$\angle C = 180^\circ - 52^\circ = 128^\circ$. Перевірка: $90^\circ + 90^\circ + 128^\circ + 52^\circ = 360^\circ$ ✓</span>
</Zavdannia>

<Zavdannia vidpovid="30" pidkazka="Бічні сторони рівнобічної трапеції рівні.">
  Основи рівнобічної трапеції $6$ см і $14$ см, бічна сторона $5$ см. Знайди периметр (у см).

  <span slot="rozviazok">$P = 6 + 14 + 5 + 5 = 30$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="11" pidkazka="Діагоналі рівнобічної трапеції рівні.">
  $ABCD$ — рівнобічна трапеція, $AC = 11$ см. Знайди $BD$ (у см).

  <span slot="rozviazok">Діагоналі рівнобічної трапеції рівні: $BD = AC = 11$ см.</span>
</Zavdannia>

<Chotyrykutnyk forma="rivnobichna" strilky={[0, 1, 0, 1]} rysky={[1, 0, 1, 0]} vidrizok={[1, 3, 0.71875, 'H', true]} storony={[undefined, '4', undefined, '10']} />

<Zavdannia vidpovid="3" pidkazka="Висоти з B і C відтинають на AD два однакові відрізки, а посередині лишається відрізок, що дорівнює BC.">
  Основи рівнобічної трапеції $ABCD$: $BC = 4$ см, $AD = 10$ см. $BH$ — висота. Знайди $AH$ (у см).

  <span slot="rozviazok">Проведемо ще висоту $CK$. $HK = BC = 4$ см, а $AH = KD$. Тож $AH = (10 - 4) : 2 = 3$ см. Перевірка: $3 + 4 + 3 = 10$ ✓</span>
</Zavdannia>
