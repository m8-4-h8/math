<Pravylo nazva="Формули скороченого множення">
$$
(a + b)^2 = a^2 + 2ab + b^2 \qquad (a - b)^2 = a^2 - 2ab + b^2
$$

Квадрат першого, **плюс (мінус) подвоєний добуток**, плюс квадрат другого.
</Pravylo>

:::note[Швидко нагадати]
- $(a + b)^2 = a^2 + 2ab + b^2$.
- $(a - b)^2 = a^2 - 2ab + b^2$ — останній член усе одно «$+$».
- $(a + b)^2 \neq a^2 + b^2$: не забудь подвоєний добуток $2ab$.
- $(3x)^2 = 9x^2$ — до квадрата підносимо і число.
- В умі: $51^2 = 2500 + 100 + 1 = 2601$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Кожен член на кожен — з теми [Множення многочленів](/math/7-klas/mnozhennia-mnohochleniv/).

<Zavdannia vidpovid="5" pidkazka="Середні добутки: 3x і 2x.">
  $(x + 2)(x + 3)$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$x^2 + 3x + 2x + 6 = x^2 + 5x + 6$, коефіцієнт $5$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Квадратну клумбу зі стороною $x$ м збільшили: і довжину, і ширину — на $3$ м. Нова площа —
не $x^2 + 9$: крім квадратика $3 \times 3$, додалися ще дві смуги $x \times 3$.

$(a + b)^2 = (a + b)(a + b)$ — це [множення многочленів](/math/7-klas/mnozhennia-mnohochleniv/).

**Тепер — малюнок.** Намалюємо квадрат зі
стороною $x + 3$: вийде великий квадрат $x^2$, маленький $9$ і **два однакові** прямокутники по $3x$.

<PloshchaDobutku a={[{ k: 1, s: 1 }, { k: 3, s: 0 }]} b={[{ k: 1, s: 1 }, { k: 3, s: 0 }]} />

**І лише тепер — правило.** Два прямокутники разом — це $2 \cdot x \cdot 3 = 6x$, той самий **подвоєний добуток**. Формула просто економить
кроки: не множимо кожен на кожен, а одразу пишемо три члени.

Для різниці середні клітинки від'ємні, тому подвоєний добуток іде зі знаком «−», а останній член — усе одно «+»:

<PloshchaDobutku a={[{ k: 1, s: 1 }, { k: -4, s: 0 }]} b={[{ k: 1, s: 1 }, { k: -4, s: 0 }]} />

**Рахуємо в умі.** $51^2 = (50 + 1)^2 = 2500 + 100 + 1 = 2601$. $99^2 = (100 - 1)^2 = 10\ 000 - 200 + 1 = 9801$.

:::tip[Чому в квадраті різниці останній член з плюсом]
$(-b) \cdot (-b) = b^2$ — мінус на мінус дає плюс. На малюнку це видно: дві середні клітинки від'ємні, а кутова —
добуток двох мінусів, тобто додатна.
:::

## Приклад

**Піднеси до квадрата $(3x - 2)^2$.**

1. Квадрат першого: $(3x)^2 = 9x^2$.
2. Подвоєний добуток: $2 \cdot 3x \cdot 2 = 12x$, знак «−».
3. Квадрат другого: $2^2 = 4$.
4. Відповідь: $9x^2 - 12x + 4$.
5. **Перевірка:** підставимо $x = 2$. Зліва: $(6 - 2)^2 = 16$. Справа: $36 - 24 + 4 = 16$ ✓

## Спробуй сам

<Zavdannia vidpovid="−20" pidkazka="Подвоєний добуток: 2 · 2x · 5, знак «−».">
  $(2x - 5)^2$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$4x^2 - 20x + 25$, коефіцієнт $-20$. Перевірка при $x = 1$: $(2 - 5)^2 = 9$ і $4 - 20 + 25 = 9$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
$(a + b)^2 \neq a^2 + b^2$! Наприклад, $(3 + 4)^2 = 49$, а $3^2 + 4^2 = 25$. Різниця $24$ — це якраз
подвоєний добуток $2 \cdot 3 \cdot 4$. І в $(3x)^2$ у квадрат підносимо і число: $9x^2$, а не $3x^2$.

**Забули подвоїти.** $(x + 5)^2 = x^2 + 5x + 25$ — неправильно: середній член $2 \cdot x \cdot 5 = 10x$. Як помітити: на
малюнку **дві** однакові смуги, а не одна; або підстав $x = 1$ — $36$, а не $31$.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="10" pidkazka="Подвоєний добуток: 2 · x · 5.">
  $(x + 5)^2$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$x^2 + 10x + 25$. Коефіцієнт — $10$.</span>
</Zavdannia>

<Zavdannia vidpovid="36" pidkazka="Квадрат другого: 6² — завжди з плюсом.">
  $(y - 6)^2$. Яке число (вільний член) вийде у відповіді?

  <span slot="rozviazok">$y^2 - 12y + 36$. Вільний член — $36$.</span>
</Zavdannia>

<Zavdannia vidpovid="12" pidkazka="2 · 2a · 3 = ?">
  $(2a + 3)^2$. Який коефіцієнт при $a$ у відповіді?

  <span slot="rozviazok">$4a^2 + 12a + 9$. Коефіцієнт при $a$ — $12$.</span>
</Zavdannia>

<Zavdannia vidpovid="1681" pidkazka="41 = 40 + 1. Тоді 1600 + 80 + 1.">
  Обчисли в умі $41^2$.

  <span slot="rozviazok">$(40 + 1)^2 = 1600 + 80 + 1 = 1681$.</span>
</Zavdannia>

<Zavdannia vidpovid="9604" pidkazka="98 = 100 − 2. Тоді 10 000 − 400 + 4.">
  Обчисли в умі $98^2$.

  <span slot="rozviazok">$(100 - 2)^2 = 10\ 000 - 400 + 4 = 9604$.</span>
</Zavdannia>

<Zavdannia vidpovid="12" pidkazka="Розпиши обидва квадрати: x² + 6x + 9 і x² − 6x + 9.">
  Спрости $(x + 3)^2 - (x - 3)^2$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$x^2 + 6x + 9 - x^2 + 6x - 9 = 12x$. Коефіцієнт — $12$.</span>
</Zavdannia>
