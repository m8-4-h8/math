<Pravylo nazva="Спільний множник">
**Розкласти на множники** — записати многочлен як **добуток**.

Спільний множник = **НСД коефіцієнтів** · кожна спільна буква з **найменшим** показником. Виносимо його за дужки, а в
дужках пишемо, що залишилось від кожного члена.
</Pravylo>

## Що це таке

Це [розподільний закон](/math/6-klas/rozkryttia-duzhok/) навпаки. Розкрити дужки: $3x(2x - 5) = 6x^2 - 15x$.
Винести за дужки — повернутися назад: $6x^2 - 15x = 3x(2x - 5)$.

Число шукаємо як [НСД](/math/5-klas/nsd-i-nsk/) коефіцієнтів, букву — з найменшим показником, бо більший
показник «не вміститься» в менший член.

<VynesenniaMnozhnyka chleny={[{ k: 6, s: 2 }, { k: -15, s: 1 }]} />

Членів може бути більше — множник виносимо з **кожного**:

<VynesenniaMnozhnyka chleny={[{ k: 4, s: 3 }, { k: 8, s: 2 }, { k: -12, s: 1 }]} />

Якщо перший член від'ємний, зручно винести мінус разом із множником — тоді в дужках усі знаки зміняться:

<VynesenniaMnozhnyka chleny={[{ k: -2, s: 2 }, { k: -6, s: 1 }]} />

Спільним множником може бути й **дужка**: $a(x + 1) + 3(x + 1) = (x + 1)(a + 3)$. На цьому побудований
[спосіб групування](/math/7-klas/sposib-hrupuvannia/).

## Приклад

**Розклади на множники $12x^4 - 18x^3 + 6x^2$.**

<VynesenniaMnozhnyka chleny={[{ k: 12, s: 4 }, { k: -18, s: 3 }, { k: 6, s: 2 }]} />

**Перевірка:** розкриємо дужки: $6x^2 \cdot 2x^2 - 6x^2 \cdot 3x + 6x^2 \cdot 1 = 12x^4 - 18x^3 + 6x^2$ ✓

:::caution[Не плутай]
Коли член повністю «пішов» у спільний множник, у дужках від нього залишається $1$, а не $0$: $6x^2 = 6x^2 \cdot 1$.
Без цієї одиниці в дужках загубиться цілий член.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="3" pidkazka="15 : 5 = ?">
  $5x + 15 = 5(x + \,?)$. Впиши число.

  <span slot="rozviazok">$15 : 5 = 3$, тому $5(x + 3)$.</span>
</Zavdannia>

<Zavdannia vidpovid="2" pidkazka="14a : 7a = ?">
  $7a^2 - 14a = 7a(a - \,?)$. Впиши число.

  <span slot="rozviazok">$7a^2 : 7a = a$, $14a : 7a = 2$. Відповідь: $7a(a - 2)$.</span>
</Zavdannia>

<Zavdannia vidpovid="4" pidkazka="НСД(8, 12) = ?">
  Яке число винесемо за дужки в $8x^3 + 12x^2$?

  <span slot="rozviazok">$\text{НСД}(8, 12) = 4$. Повністю: $4x^2(2x + 3)$.</span>
</Zavdannia>

<Zavdannia vidpovid="2" pidkazka="Найменший показник букви y серед членів.">
  $9y^3 + 6y^2$. У якому степені винесемо $y$?

  <span slot="rozviazok">Показники $3$ і $2$, найменший — $2$. $9y^3 + 6y^2 = 3y^2(3y + 2)$.</span>
</Zavdannia>

<Zavdannia vidpovid="3700" pidkazka="Винеси 37 за дужки.">
  Обчисли зручним способом $37 \cdot 56 + 37 \cdot 44$.

  <span slot="rozviazok">$37 \cdot (56 + 44) = 37 \cdot 100 = 3700$.</span>
</Zavdannia>

<Zavdannia vidpovid="4" pidkazka="Спільний множник тут — дужка (x − 3).">
  $x(x - 3) + 4(x - 3) = (x - 3)(x + \,?)$. Впиши число.

  <span slot="rozviazok">Виносимо $(x - 3)$: залишаються $x$ і $4$. Відповідь: $(x - 3)(x + 4)$.</span>
</Zavdannia>
