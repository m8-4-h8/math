<Pravylo nazva="Рівнобедрений трикутник">
Трикутник, у якого **дві сторони рівні**, називають **рівнобедреним**. Рівні сторони — **бічні**, третя сторона —
**основа**, кут між бічними сторонами — **кут при вершині**.

**Властивості.** У рівнобедреному трикутнику:

1. кути при основі **рівні**;
2. бісектриса, проведена до основи, є також **медіаною** і **висотою**.

**Ознака.** Якщо в трикутнику два кути рівні, то він рівнобедрений: рівні сторони лежать навпроти рівних кутів.
</Pravylo>

:::note[Швидко нагадати]
- Бічні сторони рівні, кути при основі рівні.
- Кут при вершині $\beta$ → кожен кут при основі $(180^\circ - \beta) : 2$.
- Кут при основі $\alpha$ → кут при вершині $180^\circ - 2\alpha$.
- Відрізок з вершини до основи: бісектриса = медіана = висота.
- Два кути рівні → трикутник рівнобедрений.
- Міні-приклад: кут при вершині $40^\circ$ → кути при основі по $70^\circ$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Що це таке

**Спершу — з життя.** Дах будинку, вішалка для одягу, «будиночок» з двох однакових карт — усе це рівнобедрені
трикутники. Склади аркуш навпіл і виріж трикутник від лінії згину. Розгорнеш — і отримаєш рівнобедрений трикутник. Його
половинки збігаються, тож кути при основі однакові. А лінія згину ділить кут при вершині навпіл, ділить основу навпіл і
стоїть до неї під прямим кутом.

**Тепер — малюнок.** $AB = BC$ — бічні сторони, $AC$ — основа, $B$ — вершина. Дуги показують рівні кути при основі, а
$BD$ — це та сама лінія згину:

<Rivnobedrenyi vidrizok={{ mediana: true, bisektrysa: true, vysota: true }} />

$BD$ водночас ділить кут $B$ навпіл (бісектриса), ділить основу навпіл (медіана) і перпендикулярна до неї (висота).

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому це правда]
Нехай $AB = BC$, а $BD$ — бісектриса. У трикутниках $ABD$ і $CBD$: $AB = CB$, $\angle ABD = \angle CBD$, $BD$ — спільна.
За [першою ознакою](/math/7-klas/persha-oznaka-rivnosti/) $\triangle ABD = \triangle CBD$. Звідси:

- $\angle A = \angle C$ — кути при основі рівні;
- $AD = DC$ — отже, $BD$ медіана;
- $\angle ADB = \angle CDB$, а разом вони $180^\circ$, тож кожен по $90^\circ$ — отже, $BD$ висота.
:::

## Приклад

**У рівнобедреному трикутнику $ABC$ з основою $AC$ кут $B$ дорівнює $48^\circ$. Знайди кути при основі.**

<Rivnobedrenyi vershyna={48} pidpysyKut={{ vershyna: '48°', osnova1: '?' }} />

1. Кути при основі рівні: позначимо кожен $x$.
2. [Сума кутів трикутника](/math/7-klas/suma-kutiv-trykutnyka/): $x + x + 48 = 180$.
3. $2x = 132$, $x = 66$.
4. Відповідь: $\angle A = \angle C = 66^\circ$.
5. **Перевірка:** $66^\circ + 66^\circ + 48^\circ = 180^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="110" pidkazka="Обидва кути при основі по 35°. Скільки лишається на кут при вершині?">
  Кут при основі рівнобедреного трикутника дорівнює $35^\circ$. Знайди кут при вершині.

  <span slot="rozviazok">Кути при основі рівні: $35^\circ$ і $35^\circ$. Кут при вершині: $180^\circ - 2 \cdot 35^\circ = 110^\circ$. Перевірка: $35 + 35 + 110 = 180$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Рівні кути — при основі.** Кут при вершині може бути гострим, прямим чи тупим. А кут при основі завжди гострий: два
тупі чи два прямі кути в трикутнику не вмістяться.

**Бісектриса = медіана = висота — лише до основи.** Відрізки, проведені до бічної сторони, зазвичай різні.

**Основа не завжди внизу.** Основа — це сторона між **рівними кутами**, а не та, що знизу. Тут основа $AC$ стоїть
збоку:
:::

## Перевір себе

Впиши відповідь або обери варіант. Одиниці можна не писати. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="55" pidkazka="180° − 70° — це два рівні кути при основі разом.">
  $AB = BC$. Знайди кут $C$.

  <Rivnobedrenyi vershyna={70} pidpysyKut={{ vershyna: '70°', osnova2: '?' }} />

  <span slot="rozviazok">Кути при основі рівні й разом дають $180^\circ - 70^\circ = 110^\circ$. Кожен: $110^\circ : 2 = 55^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="36" pidkazka="Два кути при основі разом — 2 · 72°.">
  Кут при основі рівнобедреного трикутника дорівнює $72^\circ$. Знайди кут при вершині.

  <span slot="rozviazok">$180^\circ - 2 \cdot 72^\circ = 36^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="40" pidkazka="Медіана до основи рівнобедреного трикутника — ще й бісектриса.">
  $BD$ — медіана рівнобедреного трикутника $ABC$ з основою $AC$, $\angle ABC = 80^\circ$. Знайди $\angle ABD$.

  <Rivnobedrenyi vershyna={80} kuty={false} vidrizok={{ mediana: true }} pidpysyKut={{ polovyna: '?' }} />

  <span slot="rozviazok">Медіана, проведена до основи, є й бісектрисою: $\angle ABD = 80^\circ : 2 = 40^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="9" pidkazka="Висота до основи рівнобедреного трикутника — ще й медіана.">
  $BD$ — висота рівнобедреного трикутника $ABC$ з основою $AC$, $AC = 18$ см. Знайди $AD$.

  <Rivnobedrenyi kuty={false} vidrizok={{ vysota: true }} pidpysySt={{ polovyna: '?' }} />

  <span slot="rozviazok">Висота до основи є й медіаною, тож $D$ — середина $AC$: $AD = 18 : 2 = 9$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="7" pidkazka="Два кути рівні — отже, трикутник рівнобедрений. Які сторони лежать навпроти рівних кутів?">
  $\angle A = \angle C = 50^\circ$, $AB = 7$ см. Знайди $BC$.

  <Rivnobedrenyi vershyna={80} storony={false} kuty={false} pidpysyKut={{ osnova1: '50°', osnova2: '50°' }} pidpysySt={{ bichna: '7 см', bichna2: '?' }} />

  <span slot="rozviazok">За ознакою трикутник рівнобедрений: навпроти рівних кутів $A$ і $C$ лежать рівні сторони $BC$ і $AB$. Отже, $BC = 7$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="11" pidkazka="Відніми основу від периметра — лишаться дві рівні бічні сторони.">
  Периметр рівнобедреного трикутника — $30$ см, основа — $8$ см. Знайди бічну сторону.

  <span slot="rozviazok">Дві бічні сторони разом: $30 - 8 = 22$ см. Кожна: $22 : 2 = 11$ см. Перевірка: $11 + 11 + 8 = 30$ ✓</span>
</Zavdannia>

<Zavdannia vidpovid="40" pidkazka="Зовнішній кут і кут C — суміжні. Тоді знайди кут при основі, а за ним — кут B.">
  $AB = BC$, зовнішній кут при вершині $C$ дорівнює $110^\circ$. Знайди кут $B$.

  <Rivnobedrenyi vershyna={40} pidpysyKut={{ zovnishnii: '110°', vershyna: '?' }} />

  <span slot="rozviazok">Кут $C$ дорівнює $180^\circ - 110^\circ = 70^\circ$, і $\angle A = \angle C = 70^\circ$. Кут $B$: $180^\circ - 70^\circ - 70^\circ = 40^\circ$.</span>
</Zavdannia>

  <span slot="rozviazok">Ні. Тоді обидва кути при основі тупі, і разом вони вже більші за $180^\circ$ — а це сума всіх трьох кутів.</span>

### Змішане повторення

<Zavdannia vidpovid="12" pidkazka="Чи рівні трикутники? Яка сторона відповідає AB?">
  У трикутниках $ABC$ і $KMN$: $AC = KN$, $\angle A = \angle K$, $\angle C = \angle N$, $AB = 12$ см. Знайди $KM$.

  <span slot="rozviazok">За [другою ознакою](/math/7-klas/druha-oznaka-rivnosti/) $\triangle ABC = \triangle KMN$, тож $KM = AB = 12$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="32" pidkazka="При множенні степенів з однаковою основою показники додають.">
  Обчисли $2^3 \cdot 2^2$.

  <span slot="rozviazok">[Властивості степеня](/math/7-klas/vlastyvosti-stepenia/): $2^3 \cdot 2^2 = 2^5 = 32$.</span>
</Zavdannia>
