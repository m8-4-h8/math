- Одночлен на многочлен: множимо одночлен на **кожен** член многочлена.
- Многочлен на многочлен: **кожен** член першого множимо на **кожен** член другого, потім **зводимо подібні**.
</Pravylo>

## Що це таке

Це той самий [розподільний закон](/math/6-klas/rozkryttia-duzhok/), що й $3(x - 4) = 3x - 12$, тільки тепер перед
дужками може стояти одночлен з буквою. Множимо за [властивостями степеня](/math/7-klas/vlastyvosti-stepenia/):
$2x \cdot x^2 = 2x^3$.

Зручно уявити добуток як **площу прямокутника**: сторони поділено на частини-члени, а кожна клітинка — добуток своїх
членів. Уся площа — сума всіх клітинок.

<PloshchaDobutku a={[{ k: 2, s: 1 }]} b={[{ k: 1, s: 2 }, { k: -3, s: 1 }, { k: 5, s: 0 }]} />

Коли обидва множники — многочлени, клітинок стає більше. Однаковим кольором позначено подібні члени — їх зводимо:

## Приклад

**Перемнож $(x - 2)(x^2 + 2x + 4)$.**

<PloshchaDobutku a={[{ k: 1, s: 1 }, { k: -2, s: 0 }]} b={[{ k: 1, s: 2 }, { k: 2, s: 1 }, { k: 4, s: 0 }]} />

1. $x$ на кожен член: $x^3 + 2x^2 + 4x$.
2. $-2$ на кожен член: $-2x^2 - 4x - 8$.
3. Зводимо подібні: $2x^2 - 2x^2 = 0$, $4x - 4x = 0$. Залишається $x^3 - 8$.
4. **Перевірка:** підставимо $x = 3$. Зліва: $(3 - 2)(9 + 6 + 4) = 1 \cdot 19 = 19$. Справа: $27 - 8 = 19$ ✓

:::caution[Не плутай]
$(x + 3)(x + 2) \neq x^2 + 6$! Забули «середні» добутки $2x$ і $3x$. Порахуй клітинки: $2$ члени на $2$ члени —
це $4$ добутки, і всі вони мають бути у відповіді до зведення подібних.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="−15" pidkazka="3a · (−5) = ?">
  $3a(2a - 5)$. Який коефіцієнт при $a$ у відповіді?

  <span slot="rozviazok">$3a \cdot 2a - 3a \cdot 5 = 6a^2 - 15a$. Коефіцієнт при $a$ — $-15$.</span>
</Zavdannia>

<Zavdannia vidpovid="9" pidkazka="Середні добутки: 5x і 4x.">
  $(x + 4)(x + 5)$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$x^2 + 5x + 4x + 20 = x^2 + 9x + 20$. Коефіцієнт — $9$.</span>
</Zavdannia>

<Zavdannia vidpovid="−21" pidkazka="Вільний член — добуток чисел: (−3) · 7.">
  $(x - 3)(x + 7)$. Яке число (вільний член) вийде у відповіді?

  <span slot="rozviazok">$x^2 + 7x - 3x - 21 = x^2 + 4x - 21$. Вільний член — $-21$.</span>
</Zavdannia>

<Zavdannia vidpovid="−1" pidkazka="Середні добутки: 2x · (−2) і 1 · 3x.">
  $(2x + 1)(3x - 2)$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$6x^2 - 4x + 3x - 2 = 6x^2 - x - 2$. Коефіцієнт при $x$ — $-1$.</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="Кожен з 3 членів множимо на кожен з 2.">
  Скільки добутків вийде (до зведення подібних) у $(a + b + c)(x + y)$?

  <span slot="rozviazok">$3 \cdot 2 = 6$: $ax + ay + bx + by + cx + cy$.</span>
</Zavdannia>

<Zavdannia vidpovid="−22" pidkazka="Спершу спрости: (x + 2)(x − 5) = x² − 3x − 10. Тоді x² скоротиться.">
  Знайди значення $(x + 2)(x - 5) - x^2$ при $x = 4$.

  <span slot="rozviazok">$x^2 - 3x - 10 - x^2 = -3x - 10 = -12 - 10 = -22$. Перевірка: $6 \cdot (-1) - 16 = -22$ ✓</span>
</Zavdannia>
