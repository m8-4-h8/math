<Pravylo nazva="Многочлен">
**Многочлен** — сума одночленів. Кожен одночлен у ньому — **член** многочлена.

**Подібні члени** мають однакову буквену частину — їх зводимо: додаємо коефіцієнти.

**Степінь многочлена** — найбільший зі степенів його членів (після зведення подібних).
</Pravylo>

## Що це таке

Многочлен — як потяг з вагончиків-[одночленів](/math/7-klas/odnochleny/): $3x^2 - 5x + 7$ складається з членів
$3x^2$, $-5x$ і $7$. Знак перед членом їде разом із ним.

Якщо у многочлені є **подібні** члени (однакові букви в однакових степенях), його можна спростити. Однакові «вагончики»
нижче пофарбовано одним кольором:

<PodibniChleny chleny={[{ k: 3, b: 'x²' }, { k: -5, b: 'x' }, { k: 1, b: 'x²' }, { k: 2, b: 'x' }, { k: 7 }]} />

Многочлен, у якому всі члени — одночлени стандартного вигляду і подібних серед них немає, має **стандартний вигляд**.
Тут це $4x^2 - 3x + 7$, його степінь — $2$.

:::tip[Подібні — це однакові букви з однаковими показниками]
$3x^2$ і $x^2$ — подібні. $3x^2$ і $3x$ — **ні**: показники різні. $2ab$ і $-5ba$ — подібні, бо $ba = ab$.
:::

**Додавання і віднімання.** Розкриваємо дужки (перед мінусом усі знаки в дужках змінюються) і зводимо подібні:

<RozkryttiaDuzhok mnozhnyk={-1} dodanky={[{ k: 3, b: 'a' }, { k: -4, b: 'b' }]} />

$(5a - 2b) - (3a - 4b) = 5a - 2b - 3a + 4b = 2a + 2b$.

## Приклад

**Спрости $(4x^2 - 3x + 2) - (x^2 - 5x + 6)$.**

1. Розкриваємо дужки, у других змінюємо всі знаки: $4x^2 - 3x + 2 - x^2 + 5x - 6$.
2. Зводимо подібні:

<PodibniChleny chleny={[{ k: 4, b: 'x²' }, { k: -3, b: 'x' }, { k: 2 }, { k: -1, b: 'x²' }, { k: 5, b: 'x' }, { k: -6 }]} />

3. Відповідь: $3x^2 + 2x - 4$.
4. **Перевірка:** підставимо $x = 1$. Початковий вираз: $(4 - 3 + 2) - (1 - 5 + 6) = 3 - 2 = 1$.
   Відповідь: $3 + 2 - 4 = 1$ ✓

:::caution[Не плутай]
Віднімаючи многочлен, мінус змінює знак **кожного** члена в дужках, а не лише першого:
$-(x^2 - 5x + 6) = -x^2 + 5x - 6$. І не додавай неподібні: $3x^2 + 2x$ — це не $5x^3$, так і залишається.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="4" pidkazka="Знайди член з найбільшим показником.">
  Який степінь многочлена $3x^4 - 2x^2 + 7$?

  <span slot="rozviazok">Члени мають степені $4$, $2$ і $0$. Найбільший — $4$.</span>
</Zavdannia>

<Zavdannia vidpovid="4" pidkazka="Подібні до 3b: b. 3 + 1 = ?">
  Спрости $5a + 3b - 2a + b$. Який коефіцієнт при $b$?

  <span slot="rozviazok">$5a - 2a = 3a$, $3b + b = 4b$. Відповідь: $3a + 4b$, коефіцієнт при $b$ — $4$.</span>
</Zavdannia>

<Zavdannia vidpovid="2" pidkazka="Додай коефіцієнти при x: −3 і 5.">
  $(2x^2 - 3x + 1) + (x^2 + 5x - 4)$. Який коефіцієнт при $x$ у відповіді?

  <span slot="rozviazok">$3x^2 + 2x - 3$, коефіцієнт при $x$ — $2$.</span>
</Zavdannia>

<Zavdannia vidpovid="5" pidkazka="−(2y − 8) = −2y + 8.">
  $(7y - 3) - (2y - 8)$. Яке число (вільний член) вийде у відповіді?

  <span slot="rozviazok">$7y - 3 - 2y + 8 = 5y + 5$. Вільний член — $5$.</span>
</Zavdannia>

<Zavdannia vidpovid="4" pidkazka="Степінь члена — сума показників усіх його букв.">
  Який степінь многочлена $2x^3y - x^2y^2 + 5xy$?

  <span slot="rozviazok">Степені членів: $3 + 1 = 4$, $2 + 2 = 4$, $1 + 1 = 2$. Найбільший — $4$.</span>
</Zavdannia>

<Zavdannia vidpovid="12" pidkazka="Спершу зведи подібні: 2x² + 2x. Потім підстав x = −3.">
  Знайди значення $3x^2 - 2x + 4x - x^2$ при $x = -3$.

  <span slot="rozviazok">$2x^2 + 2x = 2 \cdot 9 + 2 \cdot (-3) = 18 - 6 = 12$.</span>
</Zavdannia>
