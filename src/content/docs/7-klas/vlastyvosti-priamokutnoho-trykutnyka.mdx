<Pravylo nazva="Катет навпроти кута 30°">
У прямокутному трикутнику катет, що лежить **навпроти кута $30^\circ$**, дорівнює **половині гіпотенузи**.

**Обернене твердження.** Якщо катет дорівнює половині гіпотенузи, то кут, що лежить навпроти цього катета, дорівнює
$30^\circ$.

$\angle C = 90^\circ$, $\angle B = 30^\circ$ $\Rightarrow$ $AC = AB : 2$, тобто $AB = 2 \cdot AC$.
</Pravylo>

:::note[Швидко нагадати]
- Навпроти $30^\circ$ — катет, що вдвічі менший за гіпотенузу: $AB = 14$ см → $AC = 7$ см.
- Гіпотенуза вдвічі більша за цей катет: катет $6$ см → гіпотенуза $12$ см.
- Дано кут $60^\circ$ → спершу знайди другий гострий кут: $90^\circ - 60^\circ = 30^\circ$.
- Катет — половина гіпотенузи → навпроти нього $30^\circ$, а другий гострий кут — $60^\circ$.
- Катет навпроти $60^\circ$ — **не** половина гіпотенузи: він довший.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Ця властивість «народжується» з рівностороннього трикутника. Перевір, чи пам'ятаєш його кути:

<Zavdannia vidpovid="60" pidkazka="Усі кути рівні, а разом дають 180°.">
  Усі сторони трикутника рівні. Чому дорівнює кожен його кут?

  <span slot="rozviazok">Навпроти рівних сторін лежать рівні кути, тож усі три кути рівні: $180^\circ : 3 = 60^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Виріж з паперу рівносторонній трикутник і склади його навпіл. Лінія згину — це висота, і кожна
половинка — прямокутний трикутник з кутами $90^\circ$, $60^\circ$ і $30^\circ$. Його гіпотенуза — ціла сторона
великого трикутника, а короткий катет — половина основи, тобто **половина тієї самої сторони**.

Те саме бачать будівельники: дошка завдовжки $4$ м, покладена під кутом $30^\circ$ до землі, піднімається рівно на
$2$ м — на половину своєї довжини.

**Тепер — малюнок.** Рівносторонній трикутник зі стороною $8$ см і висотою $BD$. Висота ділить кут $B$ навпіл
($30^\circ$) і ділить основу навпіл ($4$ см):

<Rivnobedrenyi vershyna={60} vidrizok={{ vysota: true }} pidpysyKut={{ polovyna: '30°', osnova1: '60°' }} pidpysySt={{ bichna: '8 см', polovyna: '4 см' }} />

У прямокутному трикутнику $ABD$ навпроти кута $30^\circ$ лежить катет $AD = 4$ см — рівно половина гіпотенузи
$AB = 8$ см. Окремо такий трикутник виглядає так:

<KutyTrykutnyka forma="priamokutnyi2" litery={['A', 'C', 'B']} priamyi pidpysy={['60°', undefined, '30°']} pidpysySt={['a', undefined, '2a']} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому це правда]
Нехай $\angle C = 90^\circ$, $\angle B = 30^\circ$, тоді $\angle A = 60^\circ$. Прикладемо до трикутника $ABC$ його
дзеркальну копію по катету $BC$: точка $A$ перейде в точку $A_1$ на продовженні $AC$, і $CA_1 = AC$.

У трикутнику $ABA_1$ усі кути по $60^\circ$: $\angle A = \angle A_1 = 60^\circ$, а $\angle ABA_1 = 30^\circ + 30^\circ$.
Отже, він рівносторонній, і $AB = AA_1 = 2 \cdot AC$.

Обернене доводять так само: якщо $AB = 2 \cdot AC$, то $AB = AA_1 = BA_1$, трикутник $ABA_1$ рівносторонній, кут
$ABA_1$ дорівнює $60^\circ$, а його половина $\angle ABC = 30^\circ$.
:::

## Приклад

**У трикутнику $ABC$ $\angle C = 90^\circ$, $\angle A = 60^\circ$, $AB = 14$ см. Знайди $AC$.**

<KutyTrykutnyka forma="priamokutnyi2" litery={['A', 'C', 'B']} priamyi pidpysy={['60°']} pidpysySt={['?', undefined, '14 см']} />

1. Кут $30^\circ$ не дано — знайдемо його: $\angle B = 90^\circ - 60^\circ = 30^\circ$.
2. Навпроти кута $B$ лежить катет $AC$.
3. Він дорівнює половині гіпотенузи: $AC = 14 : 2 = 7$ см.
4. **Перевірка:** гіпотенуза вдвічі більша за катет: $2 \cdot 7 = 14$ ✓

## Спробуй сам

<Zavdannia vidpovid="12" pidkazka="Катет BC лежить навпроти кута 30°. Яка частина гіпотенузи — цей катет?">
  У трикутнику $ABC$ $\angle C = 90^\circ$, $\angle A = 30^\circ$, $BC = 6$ см. Знайди $AB$.

  <KutyTrykutnyka forma="priamokutnyi2" litery={['B', 'C', 'A']} priamyi pidpysy={[undefined, undefined, '30°']} pidpysySt={['6 см', undefined, '?']} />

  <span slot="rozviazok">Катет $BC$ лежить навпроти кута $A = 30^\circ$, тож він — половина гіпотенузи. Гіпотенуза вдвічі більша: $AB = 2 \cdot 6 = 12$ см. Перевірка: $12 : 2 = 6$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Половина гіпотенузи — лише катет навпроти $30^\circ$.** Катет навпроти $60^\circ$ довший: навпроти більшого кута
лежить [більша сторона](/math/7-klas/storony-i-kuty-trykutnyka/).

**Дано $60^\circ$ — спершу знайди $30^\circ$.** Інший гострий кут дорівнює $90^\circ - 60^\circ = 30^\circ$, і саме
навпроти нього шукай короткий катет.

**Гіпотенуза — удвічі більша, а не вдвічі менша.** Катет $5$ см навпроти $30^\circ$ → гіпотенуза $10$ см, а не
$2{,}5$ см: гіпотенуза — найбільша сторона.
:::

## Перевір себе

Впиши відповідь або обери варіант. Одиниці можна не писати. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="9" pidkazka="Навпроти кута 30° лежить катет, що вдвічі менший за гіпотенузу.">
  За малюнком знайди $AC$.

  <KutyTrykutnyka forma="priamokutnyi2" litery={['A', 'C', 'B']} priamyi pidpysy={[undefined, undefined, '30°']} pidpysySt={['?', undefined, '18 см']} />

  <span slot="rozviazok">Катет $AC$ лежить навпроти кута $B = 30^\circ$, тож $AC = 18 : 2 = 9$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="BC" varianty={['AC', 'BC']} pidkazka="Який катет лежить навпроти кута A?">
  У трикутнику $ABC$ $\angle C = 90^\circ$, $\angle A = 30^\circ$. Який катет дорівнює половині гіпотенузи?

  <span slot="rozviazok">Навпроти кута $A = 30^\circ$ лежить катет $BC$ — він і дорівнює половині гіпотенузи $AB$.</span>
</Zavdannia>

<Zavdannia vidpovid="30" pidkazka="Порівняй катет AC з гіпотенузою AB.">
  У трикутнику $ABC$ $\angle C = 90^\circ$, $AB = 20$ см, $AC = 10$ см. Знайди $\angle B$.

  <span slot="rozviazok">Катет $AC$ дорівнює половині гіпотенузи: $20 : 2 = 10$. Тому кут навпроти нього — кут $B$ — дорівнює $30^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="10" pidkazka="Спершу знайди кут B. Навпроти якого кута лежить AC?">
  У трикутнику $ABC$ $\angle C = 90^\circ$, $\angle A = 60^\circ$, $AC = 5$ см. Знайди $AB$.

  <span slot="rozviazok">Кут $B$ дорівнює $90^\circ - 60^\circ = 30^\circ$. Навпроти нього катет $AC$, тож гіпотенуза $AB = 2 \cdot 5 = 10$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="Знайди кути при основі. У трикутнику ABD висота — катет навпроти одного з них.">
  У трикутнику $ABC$ $AB = BC = 12$ см, $\angle B = 120^\circ$, $BD$ — висота. Знайди $BD$.

  <Rivnobedrenyi vershyna={120} kuty={false} vidrizok={{ vysota: true }} pidpysySt={{ bichna: '12 см' }} />

  <span slot="rozviazok">Кути при основі по $(180^\circ - 120^\circ) : 2 = 30^\circ$. У прямокутному трикутнику $ABD$ катет $BD$ лежить навпроти кута $A = 30^\circ$: $BD = 12 : 2 = 6$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="8" pidkazka="Зовнішній кут і кут B — суміжні.">
  У трикутнику $ABC$ $\angle C = 90^\circ$, зовнішній кут при вершині $B$ дорівнює $150^\circ$, $AB = 16$ см. Знайди $AC$.

  <span slot="rozviazok">Кут $B$ дорівнює $180^\circ - 150^\circ = 30^\circ$. Навпроти нього катет $AC$: $16 : 2 = 8$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="12" pidkazka="Гіпотенуза — це два такі катети. Скільки катетів у сумі 18 см?">
  У трикутнику $ABC$ $\angle C = 90^\circ$, $\angle B = 30^\circ$, $AB + AC = 18$ см. Знайди $AB$.

  <span slot="rozviazok">$AC$ лежить навпроти кута $30^\circ$, тож $AB = 2 \cdot AC$, і сума — це три катети $AC$: $AC = 18 : 3 = 6$ см, $AB = 2 \cdot 6 = 12$ см. Перевірка: $12 + 6 = 18$ ✓</span>
</Zavdannia>

### Змішане повторення

<Zavdannia vidpovid="22" pidkazka="Бічні сторони по 4 см можуть бути? Перевір нерівність трикутника.">
  Дві сторони рівнобедреного трикутника — $4$ см і $9$ см. Знайди його периметр.

  <span slot="rozviazok">[Нерівність трикутника](/math/7-klas/nerivnist-trykutnyka/): бічні по $4$ см не можуть бути, бо $4 + 4 = 8$ — менше за $9$. Отже, бічні по $9$ см: $9 + 9 + 4 = 22$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="Перенеси −7 у праву частину зі знаком «+».">
  Розв'яжи рівняння $3x - 7 = 11$.

  <span slot="rozviazok">[Лінійні рівняння](/math/7-klas/liniini-rivniannia/): $3x = 11 + 7 = 18$, $x = 18 : 3 = 6$. Перевірка: $3 \cdot 6 - 7 = 11$ ✓</span>
</Zavdannia>
