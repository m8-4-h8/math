<Pravylo nazva="Хорда і діаметр">
**Хорда** — відрізок, що сполучає дві точки кола. **Діаметр** — хорда, що проходить через центр. Він дорівнює двом
радіусам: $d = 2r$.

**Властивості.**

1. Діаметр — **найбільша** хорда кола.
2. Радіуси $OA$, $OB$ і хорда $AB$ утворюють **рівнобедрений** трикутник: $\angle OAB = \angle OBA$.
3. Діаметр, **перпендикулярний** до хорди, ділить її **навпіл**.
</Pravylo>

:::note[Швидко нагадати]
- Хорда — від точки кола до точки кола. Хорда через центр — діаметр, $d = 2r$.
- Діаметр — найбільша хорда: при $r = 5$ см жодна хорда не довша за $10$ см.
- Два радіуси й хорда — рівнобедрений трикутник: $\angle OAB = 35^\circ$ → $\angle AOB = 180^\circ - 70^\circ = 110^\circ$.
- Діаметр $\perp$ хорді → ділить її навпіл: $AB = 16$ см → $AM = 8$ см.
- Хорда дорівнює радіусу → трикутник $AOB$ рівносторонній, $\angle AOB = 60^\circ$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Центр, радіус і діаметр ти вже знаєш з теми [«Коло і круг»](/math/4-klas/kolo-i-kruh/) у 4 класі. Перевір, чи
пам'ятаєш:

<Zavdannia vidpovid="14" pidkazka="Діаметр — це два радіуси.">
  Радіус кола $7$ см. Знайди його діаметр.

  <span slot="rozviazok">$d = 2r = 2 \cdot 7 = 14$ см.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Розріж печиво одним прямим розрізом від краю до краю — лінія розрізу буде хордою. Розрізів можна
зробити багато, і найдовший з них проходить через центр — це діаметр. Тому піцу, щоб поділити навпіл, ріжуть саме
через центр.

**Тепер — малюнок.** $AB$ — хорда, $CD$ — діаметр (він проходить через центр $O$), $OK$ — радіус:

<KoloElementy naKoli={{ A: 200, B: 330, C: 115, D: 295, K: 35 }} vidrizky={[{ a: 'A', b: 'B' }, { a: 'C', b: 'D', k: 2 }, { a: 'O', b: 'K', k: 3 }]} literyKut={{ O: 200 }} />

Проведемо радіуси до кінців хорди $AB$ і діаметр $CD$, перпендикулярний до неї. Радіуси $OA$ і $OB$ рівні, а точка
$M$ ділить хорду навпіл:

<KoloElementy naKoli={{ A: 215, B: 325, C: 90, D: 270 }} serednia={{ M: ['A', 'B'] }} vidrizky={[{ a: 'A', b: 'B' }, { a: 'C', b: 'D', k: 2 }, { a: 'O', b: 'A', shtrykh: true }, { a: 'O', b: 'B', shtrykh: true }, { a: 'A', b: 'M', rysky: 1 }, { a: 'M', b: 'B', rysky: 1 }]} priamiKuty={[['M', 'B', 'O']]} literyKut={{ M: 300, O: 160 }} />

**Як знайти центр круглої тарілки.** Обведи її, проведи дві хорди і через середину кожної — перпендикуляр до неї.
Обидва перпендикуляри — діаметри, тож вони перетнуться в центрі:

<KoloElementy naKoli={{ A: 150, B: 215, C: 290, D: 10 }} serednia={{ M: ['A', 'B'], N: ['C', 'D'] }} priami={[{ a: 'M', b: 'O', dali: 0.25 }, { a: 'N', b: 'O', dali: 0.25 }]} vidrizky={[{ a: 'A', b: 'B' }, { a: 'C', b: 'D' }]} priamiKuty={[['M', 'B', 'O'], ['N', 'D', 'O']]} literyKut={{ M: 215, N: 290 }} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому це правда]
**Діаметр — найбільша хорда.** Якщо хорда $AB$ не проходить через центр, то $A$, $O$, $B$ — вершини трикутника. За
[нерівністю трикутника](/math/7-klas/nerivnist-trykutnyka/) $AB < OA + OB = r + r = d$.

**Діаметр, перпендикулярний до хорди, ділить її навпіл.** $OA = OB$ — радіуси, тож трикутник $AOB$
[рівнобедрений](/math/7-klas/rivnobedrenyi-trykutnyk/). $OM$ — його висота до основи $AB$, а висота до основи є й
медіаною: $AM = MB$.

**І навпаки:** діаметр, що проходить через середину хорди (не діаметра), — медіана рівнобедреного трикутника $AOB$,
отже, і висота: він перпендикулярний до хорди. Саме тому спосіб з тарілкою працює.
:::

## Приклад

**$OA$ і $OB$ — радіуси, $AB$ — хорда, $\angle OAB = 35^\circ$. Знайди $\angle AOB$.**

<KoloElementy naKoli={{ A: 215, B: 325 }} vidrizky={[{ a: 'O', b: 'A', rysky: 1 }, { a: 'O', b: 'B', rysky: 1 }, { a: 'A', b: 'B' }]} kuty={[{ v: 'A', a: 'O', b: 'B', pidpys: '35°', r: 26 }]} />

1. $OA = OB$ — це радіуси.
2. Трикутник $AOB$ рівнобедрений, тож кути при основі рівні: $\angle OBA = \angle OAB = 35^\circ$.
3. $\angle AOB = 180^\circ - 35^\circ - 35^\circ = 110^\circ$.
4. **Перевірка:** $35^\circ + 35^\circ + 110^\circ = 180^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="50" pidkazka="OA = OB. Кути при основі AB рівні й разом дають 180° − 80°.">
  $OA$ і $OB$ — радіуси, $\angle AOB = 80^\circ$. Знайди $\angle OAB$.

  <span slot="rozviazok">Трикутник $AOB$ рівнобедрений: $\angle OAB = \angle OBA = (180^\circ - 80^\circ) : 2 = 50^\circ$. Перевірка: $50 + 50 + 80 = 180$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Хорда не мусить проходити через центр.** Кожен діаметр — хорда, але не кожна хорда — діаметр.

**Радіус — не хорда.** Радіус сполучає центр з точкою кола, а хорда — дві точки кола.

**Навпіл ділить лише перпендикулярний діаметр.** Діаметр, проведений під іншим кутом, ділить хорду на нерівні
частини.
:::

## Перевір себе

Впиши відповідь або обери варіант. Одиниці можна не писати. За кожну правильну відповідь — зірочка ⭐

  <span slot="rozviazok">$KL$ проходить через центр — це діаметр. $MN$ — хорда, але не діаметр, $OP$ — радіус.</span>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Яка найбільша хорда цього кола?">

  <span slot="rozviazok">Найбільша хорда — діаметр: $2 \cdot 6 = 12$ см. Хорда $13$ см довша за діаметр — так не буває.</span>
</Zavdannia>

<Zavdannia vidpovid="9" pidkazka="Діаметр, перпендикулярний до хорди, ділить її навпіл.">
  Діаметр $CD$ перпендикулярний до хорди $AB$ і перетинає її в точці $M$, $AB = 18$ см. Знайди $AM$.

  <KoloElementy naKoli={{ A: 215, B: 325, C: 90, D: 270 }} serednia={{ M: ['A', 'B'] }} vidrizky={[{ a: 'A', b: 'B' }, { a: 'C', b: 'D', k: 2 }]} priamiKuty={[['M', 'B', 'O']]} literyKut={{ M: 300, O: 160 }} />

  <span slot="rozviazok">Діаметр, перпендикулярний до хорди, ділить її навпіл: $AM = 18 : 2 = 9$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="30" pidkazka="OA = OB, тож кути при основі AB рівні.">
  $OA$ і $OB$ — радіуси, $\angle AOB = 120^\circ$. Знайди $\angle OAB$.

  <KoloElementy naKoli={{ A: 220, B: 320 }} vidrizky={[{ a: 'O', b: 'A', rysky: 1 }, { a: 'O', b: 'B', rysky: 1 }, { a: 'A', b: 'B' }]} kuty={[{ v: 'O', a: 'A', b: 'B', pidpys: '120°' }]} />

  <span slot="rozviazok">$\angle OAB = (180^\circ - 120^\circ) : 2 = 30^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="21" pidkazka="Які сторони має трикутник AOB? Скільки серед них радіусів?">
  Хорда $AB$ дорівнює радіусу кола, радіус — $7$ см. Знайди периметр трикутника $AOB$.

  <span slot="rozviazok">$OA = OB = 7$ см — радіуси, $AB = 7$ см за умовою. Периметр: $7 + 7 + 7 = 21$ см. Трикутник рівносторонній.</span>
</Zavdannia>

<Zavdannia vidpovid="50" pidkazka="Трикутник AOB рівнобедрений. Кут BOC — зовнішній для нього.">
  $AC$ — діаметр, $B$ — точка кола, $\angle BAO = 25^\circ$. Знайди $\angle BOC$.

  <KoloElementy naKoli={{ A: 180, C: 0, B: 60 }} vidrizky={[{ a: 'A', b: 'C' }, { a: 'A', b: 'B' }, { a: 'O', b: 'B' }]} kuty={[{ v: 'A', a: 'B', b: 'O', pidpys: '25°' }, { v: 'O', a: 'B', b: 'C', pidpys: '?' }]} />

  <span slot="rozviazok">$OA = OB$, тож $\angle ABO = \angle BAO = 25^\circ$. [Зовнішній кут](/math/7-klas/suma-kutiv-trykutnyka/) $BOC$ дорівнює сумі двох кутів, не суміжних з ним: $25^\circ + 25^\circ = 50^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="так" varianty={['так', 'ні']} pidkazka="Хорда, що не проходить через центр, коротша за діаметр.">
  Діаметр кола — $20$ см, хорда $AB$ теж $20$ см. Чи проходить $AB$ через центр?

  <span slot="rozviazok">Хорда, що не проходить через центр, коротша за діаметр. $AB$ дорівнює діаметру — отже, це діаметр, і він проходить через центр.</span>
</Zavdannia>

  <span slot="rozviazok">[Катет навпроти кута 30°](/math/7-klas/vlastyvosti-priamokutnoho-trykutnyka/) — половина гіпотенузи: $BC = 22 : 2 = 11$ см.</span>
