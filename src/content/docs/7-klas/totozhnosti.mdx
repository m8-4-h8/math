<Pravylo nazva="Тотожність">
Два вирази **тотожно рівні**, якщо при **будь-яких** значеннях змінних їхні значення однакові: $2(x - 1)$ і $2x - 2$.
Рівність, правильна при будь-яких значеннях змінних, — **тотожність**.

**Довести** тотожність — перетворити одну її частину в іншу (або обидві — до одного вигляду). **Спростувати** —
знайти **одне** значення змінної, при якому частини різні.
</Pravylo>

:::note[Швидко нагадати]
- $2(x - 1) = 2x - 2$ і $\;2x + 3x = 5x$ — тотожності.
- $x + x = x^2$ — не тотожність: при $x = 3$ маємо $6 \ne 9$.
- Тотожні перетворення: розкрити дужки, звести подібні доданки, переставити доданки чи множники.
- Доводимо: ліву частину → до правої, праву → до лівої, або обидві → до одного вигляду.
- Кілька чисел, що «підійшли», — ще не доведення. Одне, що «не підійшло», — уже спростування.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Що це таке

### Тотожно рівні вирази

**Спершу — з життя.** Два зошити коштують по $x$ грн, і на кожен дали знижку $1$ грн. Оля рахує вартість так:
$2(x - 1)$, а Тарас — так: $2x - 2$. Хто правий? Підставимо кілька цін:

<PorivnianniaVyraziv a="2(x − 1)" koefA={[-2, 2]} b="2x − 2" koefB={[-2, 2]} x={[-2, -1, 0, 1, 2, 3]} />

Значення однакові. І так буде при **будь-якому** $x$: за розподільною властивістю множення $2(x - 1) = 2x - 2$. Такі
вирази називають **тотожно рівними**, або **тотожними**. Праві обоє.

А от $x + x$ і $x^2$ при $x = 0$ і $x = 2$ збігаються, але при $x = 1$ чи $x = 3$ — ні:

<PorivnianniaVyraziv a="x + x" koefA={[0, 2]} b="x²" koefB={[0, 0, 1]} x={[0, 1, 2, 3]} />

Тому вирази $x + x$ і $x^2$ **не** тотожні: щоб бути тотожними, вони мають збігатися при всіх значеннях змінної, а не
лише при деяких.

### Тотожність

**Тотожність** — рівність, правильна при будь-яких значеннях змінних. Тотожностями є всі властивості дій:

| Властивість | Тотожність |
| --- | --- |
| переставна | $a + b = b + a$, $\;ab = ba$ |
| сполучна | $(a + b) + c = a + (b + c)$ |
| розподільна | $a(b + c) = ab + ac$ |
| дії з $0$, $1$, $-1$ | $a + 0 = a$, $\;a \cdot 1 = a$, $\;a + (-a) = 0$ |

Тотожностями вважають і правильні числові рівності: $5^2 + 12^2 = 13^2$.

**Тотожність і рівняння — різні речі.** Рівняння $2x + 3 = 7$ правильне лише при $x = 2$ — його треба розв'язати.
Тотожність $2(x + 3) = 2x + 6$ правильна при будь-якому $x$ — розв'язувати нічого, її доводять.

### Тотожні перетворення

Замінити вираз тотожно рівним — це **тотожне перетворення**: розкрити дужки, звести подібні доданки, переставити
множники. Так ми **спрощуємо** вирази. Спростимо $2(3x - 4) + 3(-4x + 7)$:

1. Розкриваємо дужки: $6x - 8 - 12x + 21$.
2. Зводимо подібні доданки: $-6x + 13$, або $13 - 6x$.

### Як довести тотожність

Три способи — обирай той, де менше роботи:

1. **Ліву частину — до правої.** $2x - (x + 5) - 11 = x - 16$: $\;2x - x - 5 - 11 = x - 16$ ✓
2. **Праву частину — до лівої.** $20b - 4a = 5(2a - 3b) - 7(2a - 5b)$: права частина
   $10a - 15b - 14a + 35b = 20b - 4a$ ✓
3. **Обидві частини — до одного вигляду.** $2(3x - 8) + 4(5x - 7) = 13(2x - 5) + 21$: ліва
   $6x - 16 + 20x - 28 = 26x - 44$, права $26x - 65 + 21 = 26x - 44$ ✓

:::tip[Чому таблиця не доводить]
Змінна може набувати безлічі значень — перевірити всі неможливо. Тотожні перетворення спираються на властивості дій, а
вони правильні для **будь-яких** чисел. Тому перетворення доводить тотожність, а таблиця лише підказує, чи варто
доводити.
:::

## Приклад

**Доведи тотожність $3(a - 2) + 2(a + 1) = 5a - 4$.**

1. Права частина вже коротка — перетворюємо ліву.
2. Розкриваємо дужки: $3a - 6 + 2a + 2$.
3. Зводимо подібні: $5a - 4$ — це права частина ✓
4. **Перевірка** числом (ловить помилки, але не доводить): при $a = 1$ ліва частина
   $3 \cdot (-1) + 2 \cdot 2 = 1$, права $5 - 4 = 1$ ✓

Тотожність доведено.

## Спробуй сам

<Zavdannia vidpovid="так" varianty={['так', 'ні']} pidkazka="Розкрий дужки в лівій частині: 4x − 12 − x.">
  Чи є тотожністю рівність $4(x - 3) - x = 3x - 12$?

  <span slot="rozviazok">Ліва частина: $4x - 12 - x = 3x - 12$ — збігається з правою, отже, так. Перевірка при $x = 0$: $-12 = -12$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**«Перевірив кілька чисел — значить, тотожність».** $x + x = x^2$ правильна при $x = 0$ і $x = 2$, але при $x = 3$ —
ні. Як помітити: кілька прикладів не доводять, доводь перетвореннями. Спростовує ж і один приклад.

**Мінус перед дужками.** $-(x - 5) = -x - 5$ — неправильно: мінус змінює знак **кожного** доданка, $-(x - 5) = -x + 5$.
Як помітити: підстав $x = 0$ — ліворуч $5$, праворуч $-5$.

**Тотожність розв'язують, як рівняння.** У тотожності шукати нічого: вона правильна при всіх $x$. Як помітити: якщо після
спрощення обидві частини однакові, рівняння має безліч коренів — це тотожність.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`, десятковий дріб — з комою: `-1,5`.
За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="так" varianty={['так', 'ні']} pidkazka="Розкрий дужки: 2 · x − 2 · 3.">
  Чи тотожно рівні вирази $2(x - 3)$ і $2x - 6$?

  <span slot="rozviazok">$2(x - 3) = 2x - 6$ за розподільною властивістю — так.</span>
</Zavdannia>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Підстав x = 0 в обидва вирази.">
  Чи тотожно рівні вирази $3a - 8$ і $8 - 3a$?

  <span slot="rozviazok">При $a = 0$: $-8$ і $8$ — різні. Одного прикладу досить: ні.</span>
</Zavdannia>

<Zavdannia vidpovid="−10" pidkazka="Множимо числа окремо: −2,5 · 4.">

  <span slot="rozviazok">$-2{,}5 \cdot 4 = -10$, вираз дорівнює $-10x$.</span>
</Zavdannia>

<Zavdannia vidpovid="−6" pidkazka="Розкрий дужки: 6x − 8 − 12x + 21, потім зведи подібні.">

  <span slot="rozviazok">$6x - 8 - 12x + 21 = -6x + 13$, коефіцієнт $-6$.</span>

<Zavdannia vidpovid="10" pidkazka="Спрости ліву частину: 5x + 10 − 3x.">

  <span slot="rozviazok">$5x + 10 - 3x = 2x + 10$, у віконці $10$. Перевірка при $x = 0$: $10 = 10$ ✓</span>
</Zavdannia>

<Zavdannia vidpovid="1" pidkazka="Мінус перед другими дужками змінює обидва знаки: −2a + 8.">
  Яке число треба вписати у віконце, щоб рівність була тотожністю: $7(a - 1) - 2(a - 4) = 5a + \square$?

  <span slot="rozviazok">$7a - 7 - 2a + 8 = 5a + 1$, у віконці $1$.</span>
</Zavdannia>

<Zavdannia vidpovid="В" varianty={['А', 'Б', 'В']} pidkazka="Для кожної спробуй x = 3 (або a = 3) — і перетвори ліву частину.">
  Яка з рівностей — тотожність?
  А) $x + x = x^2$; Б) $3(a - 2) = 3a - 2$; В) $5a - 1 = -1 + 5a$.

  <span slot="rozviazok">А: при $x = 3$ маємо $6 \ne 9$. Б: $3(a - 2) = 3a - 6$, а не $3a - 2$. В: доданки лише переставлено — тотожність.</span>
</Zavdannia>
