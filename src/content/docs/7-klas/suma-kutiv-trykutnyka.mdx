<Pravylo nazva="Кути трикутника">
**Сума кутів трикутника** дорівнює $180^\circ$:

$$
\angle A + \angle B + \angle C = 180^\circ
$$

**Зовнішній кут** трикутника — кут, **суміжний** з кутом трикутника. Він дорівнює **сумі двох кутів трикутника,
не суміжних з ним**.
</Pravylo>

:::note[Швидко нагадати]
- Третій кут: $\angle C = 180^\circ - \angle A - \angle B$.
- Зовнішній кут при вершині $C$: $\angle BCD = \angle A + \angle B$ (і він же $180^\circ - \angle C$).
- Зовнішній кут більший за кожен кут трикутника, не суміжний з ним.
- У прямокутному трикутнику гострі кути разом дають $90^\circ$; прямий чи тупий кут у трикутнику — лише один.
- Міні-приклад: $\angle A = 50^\circ$, $\angle B = 60^\circ$ → $\angle C = 70^\circ$, зовнішній при $C$ — $110^\circ$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Доводитимемо за допомогою [властивостей паралельних прямих](/math/7-klas/vlastyvosti-paralelnykh/). Перевір, чи пам'ятаєш:

<Zavdannia vidpovid="70" pidkazka="Внутрішні різносторонні кути при паралельних прямих рівні.">
  $a \parallel b$. Один із внутрішніх різносторонніх кутів дорівнює $70^\circ$. Знайди другий.

  <span slot="rozviazok">При паралельних прямих внутрішні різносторонні кути рівні: $70^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Виріж з паперу будь-який трикутник, відірви в нього три кути й приклади їх вершинами один до
одного. Хоч який трикутник візьмеш — великий, маленький, «гострий», «тупий» — кути завжди складуться в
**розгорнутий кут**, тобто в $180^\circ$. Ще в [5 класі](/math/5-klas/vydy-trykutnykiv/) ми цим користувались, а тепер доведемо.

**Тепер — малюнок.** Проведемо через вершину $A$ пряму, **паралельну** $BC$. Біля вершини $A$ утворилися три кути:
$\angle 1$, $\angle A$ і $\angle 2$ — разом вони дають розгорнутий кут:

<KutyTrykutnyka paralelna kolory />

- $\angle 1 = \angle B$ — це внутрішні різносторонні кути при паралельних прямих і січній $AB$ (зелені);
- $\angle 2 = \angle C$ — внутрішні різносторонні при січній $AC$ (рожеві);
- отже, $\angle B + \angle A + \angle C = \angle 1 + \angle A + \angle 2 = 180^\circ$.

**І лише тепер — правило** — воно в рамці вгорі.

**Зовнішній кут.** Продовжимо сторону $BC$ за вершину $C$ до точки $D$. Кут $ACD$ — **зовнішній** кут трикутника при
вершині $C$: він суміжний з $\angle C$.

<KutyTrykutnyka zovnishnii={{ v: 2, pidpys: '110°', litera: 'D' }} pidpysy={['50°', '60°']} />

Суміжні кути разом $180^\circ$, тому зовнішній кут $= 180^\circ - \angle C$. А $180^\circ - \angle C = \angle A + \angle B$ —
за сумою кутів трикутника. Тут $50^\circ + 60^\circ = 110^\circ$.

:::tip[Навіщо зовнішній кут]
Він дає відповідь **за один крок**: щоб знайти зовнішній кут, не треба шукати третій кут трикутника — досить додати
два кути, не суміжні з ним. І навпаки: від зовнішнього кута віднімаємо відомий кут — отримуємо інший.
:::

## Приклад

**$\angle A = 48^\circ$, $\angle B = 77^\circ$. Знайди $\angle C$ і зовнішній кут трикутника при вершині $C$.**

1. Третій кут: $\angle C = 180^\circ - 48^\circ - 77^\circ = 55^\circ$.
2. Зовнішній кут при $C$ — сума кутів, не суміжних з ним: $48^\circ + 77^\circ = 125^\circ$.
3. **Перевірка** іншим способом: зовнішній кут суміжний з $\angle C$, тож $180^\circ - 55^\circ = 125^\circ$ ✓

## Спробуй сам

<Zavdannia vidpovid="85" pidkazka="Зовнішній кут при C дорівнює ∠A + ∠B. Відомий кут відніми.">
  Зовнішній кут трикутника $ABC$ при вершині $C$ дорівнює $130^\circ$, $\angle A = 45^\circ$. Знайди $\angle B$.

  <span slot="rozviazok">$\angle A + \angle B = 130^\circ$, тож $\angle B = 130^\circ - 45^\circ = 85^\circ$. Перевірка: $\angle C = 180^\circ - 130^\circ = 50^\circ$, і $45^\circ + 85^\circ + 50^\circ = 180^\circ$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Зовнішній кут — це сума двох кутів, не суміжних з ним**, а не всіх трьох і не суміжного кута. Суміжний з ним кут
трикутника — навпаки, доповнює його до $180^\circ$.

**Зовнішній — суміжний, а не вертикальний.** Кут, вертикальний до кута трикутника, просто дорівнює цьому куту.

**Розмір трикутника не важливий.** Великий і маленький трикутники мають ту саму суму кутів — $180^\circ$.
:::

## Перевір себе

Впиши відповідь або обери варіант. Градуси можна не писати. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="47" pidkazka="Від 180° відніми два відомі кути.">
  Знайди невідомий кут трикутника.

  <KutyTrykutnyka pidpysy={['62°', '71°', '?']} />

  <span slot="rozviazok">$180^\circ - 62^\circ - 71^\circ = 47^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="56" pidkazka="Гострі кути прямокутного трикутника разом дають 90°.">
  Один із гострих кутів прямокутного трикутника дорівнює $34^\circ$. Знайди другий гострий кут.

  <span slot="rozviazok">$90^\circ - 34^\circ = 56^\circ$ (бо $180^\circ - 90^\circ = 90^\circ$ припадає на два гострі кути).</span>
</Zavdannia>

<Zavdannia vidpovid="111" pidkazka="Зовнішній кут дорівнює сумі двох кутів, не суміжних з ним.">
  Знайди зовнішній кут трикутника при вершині $C$.

  <KutyTrykutnyka zovnishnii={{ v: 2, pidpys: '?', litera: 'D' }} pidpysy={['43°', '68°']} />

  <span slot="rozviazok">$43^\circ + 68^\circ = 111^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="ні" varianty={['так', 'ні']} pidkazka="Додай усі три кути.">
  Чи може трикутник мати кути $50^\circ$, $60^\circ$ і $80^\circ$?

  <span slot="rozviazok">Ні: $50^\circ + 60^\circ + 80^\circ = 190^\circ$, а має бути $180^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="60" pidkazka="У рівностороннього трикутника всі кути рівні.">
  Знайди кут рівностороннього трикутника.

  <span slot="rozviazok">Три рівні кути разом $180^\circ$: кожен $180^\circ : 3 = 60^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="80" pidkazka="Позначимо кути 2x, 3x, 4x: разом 9x = 180.">
  Кути трикутника відносяться як $2 : 3 : 4$. Знайди найбільший кут.

  <span slot="rozviazok">$2x + 3x + 4x = 180$, $9x = 180$, $x = 20$. Кути $40^\circ$, $60^\circ$, $80^\circ$, найбільший — $80^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="70" pidkazka="Зовнішній кут при B дорівнює ∠A + ∠C, а вони рівні.">
  Зовнішній кут трикутника $ABC$ при вершині $B$ дорівнює $140^\circ$, а $\angle A = \angle C$. Знайди $\angle A$.

  <span slot="rozviazok">$\angle A + \angle C = 140^\circ$, кути рівні: $140^\circ : 2 = 70^\circ$. Перевірка: $\angle B = 40^\circ$, $70^\circ + 70^\circ + 40^\circ = 180^\circ$ ✓</span>
</Zavdannia>
