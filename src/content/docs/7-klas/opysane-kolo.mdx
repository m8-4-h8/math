<Pravylo nazva="Серединний перпендикуляр і описане коло">
**Серединний перпендикуляр** до відрізка — пряма, що проходить через його середину перпендикулярно до нього. Кожна його
точка **однаково віддалена** від кінців відрізка. І навпаки: точка, однаково віддалена від кінців відрізка, лежить на
серединному перпендикулярі.

**Описане коло** проходить через усі вершини трикутника. Його центр — точка перетину **серединних перпендикулярів** до
сторін, і $OA = OB = OC = R$. Навколо будь-якого трикутника можна описати коло, і лише одне.

**Прямокутний трикутник.** Центр описаного кола — **середина гіпотенузи**, $R = c : 2$. Тому медіана, проведена до
гіпотенузи, дорівнює половині гіпотенузи.
</Pravylo>

:::note[Швидко нагадати]
- Серединний перпендикуляр — і через середину, і під прямим кутом.
- Точка $P$ на серединному перпендикулярі до $AB$ → $PA = PB$.
- Центр описаного кола — перетин серединних перпендикулярів: $OA = OB = OC = R$.
- Гострокутний трикутник — центр усередині, прямокутний — на середині гіпотенузи, тупокутний — поза трикутником.
- Прямокутний: гіпотенуза $10$ см → $R = 5$ см, медіана до гіпотенузи теж $5$ см.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Головний інструмент цієї теми — [рівнобедрений трикутник](/math/7-klas/rivnobedrenyi-trykutnyk/). Перевір, чи
пам'ятаєш:

<Zavdannia vidpovid="90" pidkazka="Медіана до основи рівнобедреного трикутника — ще й висота.">
  У трикутнику $PAB$ $PA = PB$, $PM$ — медіана. Знайди $\angle PMA$.

  <span slot="rozviazok">Медіана, проведена до основи рівнобедреного трикутника, є й висотою: $\angle PMA = 90^\circ$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Три будинки хочуть викопати один колодязь — так, щоб до кожного будинку було однаково далеко.
Почнемо з двох будинків $A$ і $B$. Склади карту так, щоб $A$ ліг точно на $B$: лінія згину пройде через середину $AB$
під прямим кутом. Будь-яка точка на згині однаково далеко від $A$ і $B$ — це серединний перпендикуляр:

<KoloElementy bezKola tochky={{ A: [-1.2, 0], B: [1.2, 0], P: [0, 1.4] }} serednia={{ M: ['A', 'B'] }} priami={[{ a: 'M', b: 'P', dali: 0.4 }]} vidrizky={[{ a: 'A', b: 'M', rysky: 2 }, { a: 'M', b: 'B', rysky: 2 }, { a: 'P', b: 'A', k: 2, rysky: 1 }, { a: 'P', b: 'B', k: 2, rysky: 1 }]} priamiKuty={[['M', 'B', 'P']]} literyKut={{ M: 300, P: 30 }} />

**Тепер — малюнок.** Так само складемо карту для будинків $B$ і $C$. Два згини перетнуться в точці $O$ — вона однаково
далеко від усіх трьох будинків. Третій серединний перпендикуляр пройде через ту саму точку:

<KoloElementy naKoli={{ A: 210, B: 105, C: 335 }} mnohokutnyk={['A', 'B', 'C']} kolirKola={3} serednia={{ K: ['A', 'B'], L: ['B', 'C'], N: ['A', 'C'] }} vidrizky={[{ a: 'K', b: 'O', k: 2 }, { a: 'L', b: 'O', k: 2 }, { a: 'N', b: 'O', k: 2 }]} priamiKuty={[['K', 'B', 'O'], ['L', 'C', 'O'], ['N', 'C', 'O']]} bezLiter={['K', 'L', 'N']} />

Коло з центром $O$ і радіусом $OA$ пройде через усі три вершини — це **описане коло**:

<KoloElementy naKoli={{ A: 210, B: 105, C: 335 }} mnohokutnyk={['A', 'B', 'C']} kolirKola={3} vidrizky={[{ a: 'O', b: 'A', k: 2, rysky: 1 }, { a: 'O', b: 'B', k: 2, rysky: 1 }, { a: 'O', b: 'C', k: 2, rysky: 1 }]} />

У прямокутному трикутнику центр — середина гіпотенузи:

<KoloElementy naKoli={{ A: 180, C: 0, B: 115 }} mnohokutnyk={['A', 'B', 'C']} kolirKola={3} vidrizky={[{ a: 'A', b: 'O', rysky: 1 }, { a: 'O', b: 'C', rysky: 1 }, { a: 'O', b: 'B', k: 2, rysky: 1 }]} priamiKuty={[['B', 'A', 'C']]} literyKut={{ O: 270 }} />

**І лише тепер — правило** — воно в рамці вгорі.

:::tip[Чому це правда]
**Точка на серединному перпендикулярі.** Нехай $M$ — середина $AB$, а $P$ — точка серединного перпендикуляра. У
прямокутних трикутниках $PMA$ і $PMB$ катет $PM$ спільний, а $AM = MB$. За
[двома катетами](/math/7-klas/priamokutnyi-trykutnyk/) вони рівні, тож $PA = PB$.

**Навпаки.** Якщо $PA = PB$, то трикутник $PAB$ рівнобедрений, і його медіана $PM$ — ще й висота. Отже, $P$ лежить
на серединному перпендикулярі.

**Центр описаного кола.** Точка $O$ на серединних перпендикулярах до $AB$ і $BC$: $OA = OB$ і $OB = OC$. Тоді
$OA = OC$ — і $O$ лежить на третьому серединному перпендикулярі.

**Прямокутний трикутник** ($\angle B = 90^\circ$). Проведемо з $B$ відрізок $BO$ до гіпотенузи так, щоб
$\angle OBC = \angle C$. Тоді трикутник $OBC$ рівнобедрений: $OB = OC$. А $\angle ABO = 90^\circ - \angle C = \angle A$,
тож і $OA = OB$. Отже, $OA = OB = OC$: $O$ — середина гіпотенузи і центр описаного кола.
:::

## Приклад

**У трикутнику $ABC$ $\angle C = 90^\circ$, $\angle A = 30^\circ$, $BC = 7$ см. Знайди радіус описаного кола.**

1. Катет $BC$ лежить навпроти кута $30^\circ$, тож [гіпотенуза вдвічі
   більша](/math/7-klas/vlastyvosti-priamokutnoho-trykutnyka/): $AB = 2 \cdot 7 = 14$ см.
2. Центр описаного кола — середина гіпотенузи, тож $R = AB : 2 = 14 : 2 = 7$ см.
3. **Перевірка:** $\angle B = 60^\circ$ і $OB = OC = 7$ см — трикутник $OBC$ рівносторонній, і $BC$ теж $7$ см ✓

## Спробуй сам

<Zavdannia vidpovid="26" pidkazka="Точка P на серединному перпендикулярі, тож PB = PA.">
  Точка $P$ лежить на серединному перпендикулярі до відрізка $AB$, $PA = 9$ см, $AB = 8$ см. Знайди периметр трикутника $PAB$.

  <span slot="rozviazok">$PB = PA = 9$ см. Периметр: $9 + 9 + 8 = 26$ см. Перевірка: трикутник рівнобедрений з основою $AB$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Серединний перпендикуляр — не просто перпендикуляр і не просто медіана.** Він і проходить через середину, і стоїть
під прямим кутом.

**Описане коло — серединні перпендикуляри, а не бісектриси.** Бісектриси потрібні для
[вписаного кола](/math/7-klas/vpysane-kolo/).

**Центр описаного кола не завжди всередині.** У тупокутному трикутнику він лежить поза трикутником:
:::

  <span slot="rozviazok">$R = AB : 2 = 22 : 2 = 11$ см.</span>

<Zavdannia vidpovid="7" pidkazka="M — середина гіпотенузи і центр описаного кола.">

  <span slot="rozviazok">$M$ — середина гіпотенузи, тобто центр описаного кола. $MA$, $MB$ і $MC$ — радіуси: $CM = 14 : 2 = 7$ см.</span>
</Zavdannia>

<Zavdannia vidpovid="140" pidkazka="OA = OB — радіуси описаного кола.">
  $O$ — центр кола, описаного навколо трикутника $ABC$, $\angle OAB = 20^\circ$. Знайди $\angle AOB$.

  <span slot="rozviazok">$OA = OB$, тож трикутник $AOB$ рівнобедрений: $\angle OBA = 20^\circ$, $\angle AOB = 180^\circ - 20^\circ - 20^\circ = 140^\circ$.</span>
</Zavdannia>

<Zavdannia vidpovid="13" pidkazka="PA = PB. Відніми AB від периметра.">
  Точка $P$ лежить на серединному перпендикулярі до відрізка $AB$, $AB = 10$ см, периметр трикутника $PAB$ — $36$ см. Знайди $PA$.

  <span slot="rozviazok">$PA = PB$, разом $36 - 10 = 26$ см, тож $PA = 26 : 2 = 13$ см.</span>
</Zavdannia>

  <span slot="rozviazok">[Дотична](/math/7-klas/dotychna-do-kola/) перпендикулярна до радіуса: $\angle APO = 90^\circ - 70^\circ = 20^\circ$.</span>
