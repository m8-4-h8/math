<Pravylo nazva="Сума і різниця кубів">
$$
a^3 + b^3 = (a + b)(a^2 - ab + b^2)
$$

$$
a^3 - b^3 = (a - b)(a^2 + ab + b^2)
$$

Другий множник — **неповний квадрат**: як квадрат суми чи різниці, тільки посередині стоїть $ab$, а не $2ab$.
</Pravylo>

:::note[Швидко нагадати]
- Сума кубів: $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$. Різниця: $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$.
- Знаки: у першій дужці — **той самий**, що між кубами, посередині — **протилежний**, в кінці — **завжди плюс**.
- Спершу впізнай куби: $8 = 2^3$, $27x^3 = (3x)^3$, $m^6 = (m^2)^3$.
- Неповний квадрат $a^2 \pm ab + b^2$ далі не розкладається.
- Міні-приклад: $x^3 - 8 = (x - 2)(x^2 + 2x + 4)$.

Все пам'ятаєш — [одразу до задач](#перевір-себе).
:::

## Пригадай

Куб одночлена — з теми [Одночлени](/math/7-klas/odnochleny/).

<Zavdannia vidpovid="8" pidkazka="До куба підносимо і число: 2³ = 2 · 2 · 2.">
  Піднеси до куба $(2x)^3$. Який коефіцієнт вийшов?

  <span slot="rozviazok">$(2x)^3 = 2^3 x^3 = 8x^3$, коефіцієнт $8$.</span>
</Zavdannia>

## Що це таке

**Спершу — з життя.** Склали великий куб з маленьких кубиків: $5 \cdot 5 \cdot 5 = 125$ штук. Забрали з кута кубик
$2 \times 2 \times 2$ — це $8$ штук. Залишилося $125 - 8 = 117$, тобто $5^3 - 2^3$. Тепер порахуємо те саме інакше:
розріжемо залишок на бруски.

<RiznytsiaKubiv a={5} b={2} />

Залишок — це три бруски: $(a - b) \cdot a^2$, $(a - b) \cdot ab$ і $(a - b) \cdot b^2$. Усі вони мають **однакову
товщину** $a - b$, тож її виносимо за дужки:

$$
a^3 - b^3 = (a - b)(a^2 + ab + b^2)
$$

**Перевіримо множенням.** Перемножимо $(x + 2)(x^2 - 2x + 4)$ «площею», як у темі
[Множення многочленів](/math/7-klas/mnozhennia-mnohochleniv/). Однакові кольори — подібні члени:

<PloshchaDobutku a={[{ k: 1, s: 1 }, { k: 2, s: 0 }]} b={[{ k: 1, s: 2 }, { k: -2, s: 1 }, { k: 4, s: 0 }]} />

Члени $-2x^2$ і $2x^2$, $4x$ і $-4x$ знищилися — лишилися тільки куби: $x^3 + 8 = x^3 + 2^3$. Це формула **суми кубів**.

**Чому «неповний квадрат».** Порівняй другий множник з квадратом суми чи різниці:

| Квадрат | Повний | Неповний |
| --- | --- | --- |
| різниці | $a^2 - 2ab + b^2$ | $a^2 - ab + b^2$ |
| суми | $a^2 + 2ab + b^2$ | $a^2 + ab + b^2$ |

**І лише тепер — правило** — воно в рамці вгорі. Його читають так: сума кубів двох виразів дорівнює добутку суми цих
виразів на неповний квадрат їхньої різниці; різниця кубів — добутку різниці на неповний квадрат їхньої суми.

Формули працюють і справа наліво — для **скороченого множення**: $(x + 2y)(x^2 - 2xy + 4y^2) = x^3 + 8y^3$.

:::tip[Як запам'ятати знаки]
«**Той самий — протилежний — завжди плюс**». У $a^3 - b^3$ між кубами мінус, тому $(a - b)$, посередині плюс: $+ab$, в
кінці плюс: $+b^2$. У $a^3 + b^3$ — $(a + b)$, $-ab$, $+b^2$.
:::

## Приклад

**Розклади на множники $27a^3 - 8$.**

1. Впізнаємо куби: $27a^3 = (3a)^3$, $8 = 2^3$. Між ними мінус — це різниця кубів, де перший вираз $3a$, другий $2$.
2. Перша дужка — різниця: $3a - 2$.
3. Неповний квадрат суми: квадрат першого $(3a)^2 = 9a^2$, добуток $3a \cdot 2 = 6a$, квадрат другого $2^2 = 4$. Маємо
   $9a^2 + 6a + 4$.
4. Відповідь: $(3a - 2)(9a^2 + 6a + 4)$.
5. **Перевірка** при $a = 1$: ліворуч $27 - 8 = 19$, праворуч $(3 - 2)(9 + 6 + 4) = 1 \cdot 19 = 19$ ✓

## Спробуй сам

<Zavdannia vidpovid="5" pidkazka="125 — куб якого числа? Середній член неповного квадрата — добуток x на це число, без подвоєння.">
  Яке число треба вписати у віконце: $x^3 + 125 = (x + 5)(x^2 - \square x + 25)$?

  <span slot="rozviazok">$125 = 5^3$, тож $x^3 + 125 = (x + 5)(x^2 - 5x + 25)$, у віконці $5$. Перевірка при $x = 1$: ліворуч $126$, праворуч $6 \cdot 21 = 126$ ✓</span>
</Zavdannia>

:::caution[Не плутай]
**Сума кубів — не куб суми.** $a^3 + b^3 \ne (a + b)^3$. Як помітити: підстав $a = b = 1$ — ліворуч $2$, праворуч $8$.

**Подвоєний добуток у неповному квадраті.** $x^3 - 8 = (x - 2)(x^2 + 4x + 4)$ — неправильно: посередині стоїть просто
$ab = 2x$, без подвоєння. Правильно: $(x - 2)(x^2 + 2x + 4)$. Як помітити: при $x = 1$ ліворуч $-7$, а в неправильному
записі $-1 \cdot 9 = -9$.

**Знак посередині.** У сумі кубів середній член зі знаком «мінус», у різниці — з «плюсом»: він протилежний до знака в
першій дужці. А неповний квадрат $x^2 + 2x + 4$ не згортається в $(x + 2)^2$ — той дорівнює $x^2 + 4x + 4$.
:::

## Перевір себе

Впиши відповідь і натисни «Перевірити». Від'ємне число пиши з мінусом: `-3`. За кожну правильну відповідь — зірочка ⭐

<Zavdannia vidpovid="3" pidkazka="27 = 3³. Середній член — добуток m на 3.">
  Яке число треба вписати у віконце: $m^3 - 27 = (m - 3)(m^2 + \square m + 9)$?

  <span slot="rozviazok">Різниця кубів: $m^3 - 3^3 = (m - 3)(m^2 + 3m + 9)$, у віконці $3$.</span>
</Zavdannia>

<Zavdannia vidpovid="64" pidkazka="Другий множник — неповний квадрат різниці a і 4. Отже, добуток — сума кубів.">
  Перемнож $(a + 4)(a^2 - 4a + 16)$. Яке число (вільний член) вийде у відповіді?

  <span slot="rozviazok">$(a + 4)(a^2 - 4a + 16) = a^3 + 4^3 = a^3 + 64$, вільний член $64$.</span>
</Zavdannia>

<Zavdannia vidpovid="Б" varianty={['А', 'Б', 'В']} pidkazka="Підстав x = 1: ліворуч 9. Яка права частина теж дає 9?">
  Яка з рівностей — тотожність?
  А) $x^3 + 8 = (x + 2)^3$; Б) $x^3 + 8 = (x + 2)(x^2 - 2x + 4)$; В) $x^3 + 8 = (x + 2)(x^2 - 4x + 4)$.

  <span slot="rozviazok">Б — формула суми кубів. А — куб суми, він дорівнює $x^3 + 6x^2 + 12x + 8$. У В посередині подвоєний добуток $4x$, а має бути $2x$.</span>
</Zavdannia>

<Zavdannia vidpovid="2" pidkazka="8b³ — куб якого одночлена?">
  Яке число треба вписати у віконце: $8b^3 + 1 = (\square b + 1)(4b^2 - 2b + 1)$?

  <span slot="rozviazok">$8b^3 = (2b)^3$, $1 = 1^3$, тож $(2b + 1)(4b^2 - 2b + 1)$, у віконці $2$.</span>
</Zavdannia>

<Zavdannia vidpovid="−9" pidkazka="Спершу згорни добуток: це x³ − (2y)³. Потім підставляй.">
  Знайди значення виразу $(x - 2y)(x^2 + 2xy + 4y^2)$ при $x = -2$, $y = 0{,}5$.

  <span slot="rozviazok">Вираз дорівнює $x^3 - (2y)^3$. При $y = 0{,}5$ маємо $2y = 1$, тому $(-2)^3 - 1^3 = -8 - 1 = -9$.</span>
</Zavdannia>

<Zavdannia vidpovid="−2" pidkazka="Ліва частина — різниця кубів: x³ − 8. Куби з обох боків знищаться.">
  Розв'яжи рівняння $(x - 2)(x^2 + 2x + 4) = x^3 + 4x$.

  <span slot="rozviazok">$x^3 - 8 = x^3 + 4x$, звідси $4x = -8$, $x = -2$. Перевірка: ліворуч $(-4) \cdot 4 = -16$, праворуч $-8 - 8 = -16$ ✓</span>
</Zavdannia>

<Zavdannia vidpovid="так" varianty={['так', 'ні']} pidkazka="Розклади різницю кубів: перша дужка — 115 − 15.">
  Чи ділиться число $115^3 - 15^3$ на $100$?

  <span slot="rozviazok">$115^3 - 15^3 = (115 - 15)(115^2 + 115 \cdot 15 + 15^2) = 100 \cdot (\ldots)$ — так, ділиться.</span>
</Zavdannia>

### Змішане повторення

<Zavdannia vidpovid="2499" pidkazka="51 · 49 = (50 + 1)(50 − 1).">
  Обчисли зручним способом $51 \cdot 49$.

  <span slot="rozviazok">$50^2 - 1^2 = 2500 - 1 = 2499$ — тема «Різниця квадратів».</span>
</Zavdannia>

<Zavdannia vidpovid="6" pidkazka="Середній член квадрата суми — подвоєний добуток: 2 · x · 3.">
  Яке число треба вписати у віконце: $(x + 3)^2 = x^2 + \square x + 9$?

  <span slot="rozviazok">$(x + 3)^2 = x^2 + 2 \cdot 3x + 9 = x^2 + 6x + 9$ — тема «Квадрат суми і квадрат різниці». Тут подвоєння є, а в неповному квадраті — немає.</span>
</Zavdannia>
