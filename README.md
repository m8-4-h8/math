# math
Матеріали з математики, впорядковані за класами й темами: теорія, задачі та розв'язання.

## Сайт

Адреса: https://m8-4-h8.github.io/math/

Сайт збирається на [Astro Starlight](https://starlight.astro.build/) і публікується автоматично
після кожного push у гілку `main` (див. `.github/workflows/pages.yml`).

## Як додавати матеріали

Усі сторінки лежать у `src/content/docs/`:

```
src/content/docs/
  index.mdx                головна сторінка (класи й теми підтягуються самі)
  trenazher.mdx            тренажери всіх класів (теми впереміш)
  4-klas/                  один клас = одна папка
    dilennia-kutom.mdx     одна тема = один файл (.md або .mdx з ілюстраціями)
  5-klas/
    rozriady-i-klasy.mdx
  vizualizatsiia-zadach/   розділ «Як намалювати задачу» (для всіх класів)
src/trenazhery/            генератори завдань для тренажерів (див. «Тренажери»)
  4-klas/
    dilennia-kutom.ts      той самий шлях, що й у теми
shablony/tema.mdx          шаблон нової теми (копіюй звідси)
```

- **Нова тема:** скопіюй `shablony/tema.mdx` у папку класу (або створи `.md` файл), на початку файлу вкажи заголовок:
  ```
  ---
  title: Назва теми
  ikonka: 🍕
  ---
  ```
  До меню, пошуку й карток на головній вона потрапить сама. `ikonka` — емодзі для картки на головній.
- **Новий клас:** створи папку (наприклад `6-klas`) і поклади туди першу тему. Клас сам з'явиться в меню
  та на головній (значок і колір класу підбираються автоматично, див. `src/klasy.mjs`).
- **Формули:** `$a^2 + b^2 = c^2$` у тексті, `$$ ... $$` окремим блоком.
- **Ілюстрації:** у файлі `.mdx` можна вставляти готові малюнки з `src/components/`:
  ```
  import Drib from '../../../components/Drib.astro';

  <Drib n={3} d={4} />
  ```

## Тренажери

У кожної теми є тренажер (розділ «Потренуйся» перед «Пов'язаними темами»). Завдання для нього не пишуться
вручну: їх складає **генератор** — файл `src/trenazhery/<клас>/<тема>.ts` з тією самою назвою, що й тема.
Генератор бере випадкові числа, складає з них умову і сам рахує відповідь, тож завдання не закінчуються.

```ts
// src/trenazhery/1-klas/sklad-chysla.ts (скорочено)
import type { Henerator } from '../dopomoha.ts';

export default {
  rivni: ['числа до 5', 'числа до 10', 'пари до десяти'], // що означає кожен рівень
  zavdannia(r, riven) {
    const tsile = r.chyslo(3, riven === 1 ? 5 : 10);
    const a = r.chyslo(0, tsile);
    return {
      pytannia: 'Яке число сховалось у віконці?',
      vyraz: `${tsile} = ${a} + □`,
      vidpovid: tsile - a,
      pidkazka: `Від ${a} рахуй далі до ${tsile}.`, // після другої помилки
      rozviazok: `${a} + ${tsile - a} = ${tsile}`, // після помилки і в розборі
    };
  },
} satisfies Henerator;
```

- Поля завдання й помічники (випадкові числа, `ch`/`des` для запису чисел, дроби `tdrib`, `vidpovidDrib`,
  імена `osoba`, відмінки `mnozh`) описані в `src/trenazhery/dopomoha.ts`. Формули — у `$...$`, як у темах.
- Кожен рівень — кілька **типів** завдань (приклад, віконце, задача, вибір варіанта), щоб тренажер не був
  одноманітним. Рівень 1 — як у «Прикладі» теми, рівень 3 — з пастками з «Не плутай» і задачами.
- `varianty` — для «так/ні», знаків `>`, `<`, `=` і вибору виду; кнопку порівнюємо з відповіддю точно.
- Малюнки до завдань — у `src/trenazhery/malunky.ts`: смужка-дріб `smuzhka`, координатний промінь `promin`,
  стовпчаста діаграма `diahrama`, кут `kut`, координатна площина `ploshchyna`. **Малюнок ніколи не підказує
  відповідь**: ні в підписах, ні в `aria-label` (точка не стоїть на підписаній рисці, на стовпчиках немає чисел).
- Алгебра (7 клас і далі): дитина не вводить многочлен, а відповідає числом — коефіцієнт, вільний член, число
  в клітинці або пара `(x; y)`. Многочлени записують `src/trenazhery/alhebra.ts`, системи — `systemy.ts`.
- Спільні помічники лежать поза теками `*-klas/`: кожен `.ts` у такій теці вважається генератором теми.
- **`npm test`** запускає кожен генератор сотні разів на кожному рівні й перевіряє: відповідь приймається,
  сусіднє число — ні; рівно один правильний варіант; формули розбирає KaTeX; завдань достатньо різних.
  Відповідь перераховується незалежно від генератора: приклад «… =» обчислюється, у рівність з □ чи $x$
  підставляється відповідь, а кожна рівність у розв'язку («1) 60 − 22 = 38») перевіряється. Тест іде і в CI.
  `npm test -- 5-klas/vidsotky` — лише ця тема, з прикладами завдань, щоб перечитати текст очима.
- Сторінка «Тренажер» і тренажер класу збираються самі з усіх генераторів.

## Як писати тему

Стиль узято зі шпаргалки до контрольної (5 клас): коротко, наочно, з перевіркою. Кожна тема будується однаково
(див. `shablony/tema.mdx`), і кожен блок спирається на перевірені дослідженнями прийоми навчання:

| Прийом | Що це | Де в темі |
| --- | --- | --- |
| Активне пригадування | дитина сама дістає знання з пам'яті, а не перечитує | «Пригадай» на початку, «Спробуй сам», «Перевір себе» |
| Від конкретного до абстрактного | спершу предмети й малюнок, потім число, наприкінці формула | «Що це таке» |
| Подвійне кодування | слово + картинка, де однакові речі одного кольору | компоненти з `src/components/` |
| Розібраний приклад | повний розв'язок по кроках з перевіркою | «Приклад» |
| Поступове згасання підказок | наступний приклад дитина доробляє сама | «Спробуй сам» |
| Типові помилки | показати хибний хід і чому він хибний | «Не плутай» |
| Пояснення собі | коротке «чому так», а не лише «як» | `:::tip[Чому це працює]` |
| Від простого до складного | завдання ростуть за складністю | «Перевір себе» |
| Інтерлівінг | задачі різних тем упереміш, щоб вчитися обирати спосіб | 1–2 останні завдання «Перевір себе» |
| Негайний відгук | відповідь перевіряється одразу, після другої помилки — підказка; правильну відповідь можна відкрити лише після власної спроби і порівняти зі своєю | `<Zavdannia>` |
| Два рівні входу | новачок іде по всій темі, а той, хто вже знає, — швидко пригадує тези і переходить до задач | «Швидко нагадати» |

**Програма НУШ — основа.** Набір тем, їх порядок і клас беремо з чинних програм Нової української школи:
1–4 клас — Типова освітня програма НУШ, 5–6 і 7–9 класи — модельні навчальні програми з математики, які МОН
рекомендує до підручників (Істер, Мерзляк, Скворцова та ін.). Перед темою звіряємо з програмою її місце й
**очікувані результати навчання** — саме їх дитина має вміти після теми, і на них спрямовані задачі «Перевір себе».
Програму і пункт, на який спирається тема, вказуємо в описі PR.

**Перед тим як писати — ресерч.** Для кожної нової теми спершу з'ясовуємо, як її найзрозуміліше пояснити
новачку: методичні статті й посібники для вчителів, як тему подають підручники НУШ і відомі навчальні сайти,
які в ній типові помилки й хибні уявлення дітей, яка модель або малюнок працює найкраще (числова пряма,
площа, смужки, терези…). Знайдене стає основою «Що це таке», «Не плутай» і малюнка; джерела коротко
вказуємо в описі PR.

Порядок блоків:

1. **Головне правило** на початку — `<Pravylo>`: одне-два речення, ключові слова жирним.
   Одразу під ним — **«Швидко нагадати»** (`:::note[Швидко нагадати]`): 3–5 коротких тез з формулами і
   одним міні-прикладом для учня, який уже знайомий з темою, і посилання «все пам'ятаєш —
   [одразу до задач](#перевір-себе)».
2. **«Пригадай»** — одне коротке `<Zavdannia>` на те, що потрібно знати з попередньої теми (з посиланням на неї).
   Пригадування «вмикає» потрібне знання перед новим матеріалом.
3. **«Що це таке»** — від конкретного до абстрактного: ситуація з життя → **малюнок** (компонент із таблиці
   вище; якщо потрібного немає — створи новий у `src/components/`, щоб числа можна було міняти) → лише потім
   загальне правило і **формула** окремим рядком ($$...$$), позначення пояснюємо одразу під нею.
   Короткий блок `:::tip[Чому це працює]` — коли «чому» можна пояснити одним-двома реченнями.
4. **«Приклад»** — розібраний покроково: нумеровані кроки, у кожному — що робимо і навіщо, останній крок —
   **Перевірка** з ✓.
5. **«Спробуй сам»** — такий самий приклад з іншими числами, де дитина робить кроки сама: одне `<Zavdannia>`,
   у підказці — перший крок, у розв'язку — усі кроки.
6. **«Не плутай»** — блок `:::caution[Не плутай]`: типова помилка, як вона виглядає і як її помітити.
7. **«Перевір себе»** — 5–7 завдань `<Zavdannia>` від простого до складного: спершу як у прикладі, потім з
   пасткою з «Не плутай», потім текстова задача. **Останні 1–2 завдання — змішане повторення**: задачі з
   попередніх тем цього розділу або класу, щоб дитина вчилася сама обирати спосіб. Розв'язок — у
   `<span slot="rozviazok">` (перед ним обов'язково порожній рядок). Для «так/ні» чи «який вид» —
   `varianty={[...]}`. Підказка (`pidkazka`) — наводящий крок, а не відповідь. Зірочки зберігаються в браузері
   й показуються біля теми на головній.
8. **«Потренуйся»** — `<Trenazher />` і генератор `src/trenazhery/<клас>/<тема>.ts` (див. «Тренажери»):
   завдання тих самих типів, що в «Перевір себе», але щоразу з новими числами.
9. Посилання на пов'язані теми (`/math/<клас>/<тема>/`).

Мова — українська; назви файлів і компонентів — латиницею (транслітерація). Кольори малюнків беремо з
`src/styles/ilustratsii.css` (`--ill-1`…`--ill-4`), щоб вони працювали у світлій і темній темах.

Сторінки `<N>-klas/shpargalka-do-kontrolnoi.mdx` — коротке повторення перед контрольною з посиланнями на теми.

Тема живе в тому класі, де її вперше вивчають. Якщо тему переносимо в інший клас, стару адресу додаємо в
`redirects` в `astro.config.mjs`, щоб посилання не зламались.

Локальний запуск (потрібен Node.js 22.23.4+ або 24): `npm install`, потім `npm run dev`.

Дитяча тема сайту (шрифт Nunito, кольори, круглі кнопки) — у `src/styles/dytiacha-tema.css`, логотип-сова —
`src/assets/sova.svg`.
